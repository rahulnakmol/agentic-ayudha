Rule 8: tag ruleset `v*` from `main` only

## Live result

Rulesets cannot check which commit a tag points to

## Implemented instead

Ruleset `release-tags`: creation, update, deletion and non-fast-forward of `refs/tags/v*` restricted to the repository admin. WP0.4 `release.yml` must refuse a `v*` tag whose commit is not on `main`
