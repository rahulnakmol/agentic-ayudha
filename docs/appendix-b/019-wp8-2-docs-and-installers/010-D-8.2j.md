# D-8.2j

## Plan assumption

WP0.4 and D-8.2d: goreleaser's winget manifests under `package_identifier: rahulnakmol.aayudha`; the founder (2026-10-17): the identifiers are wrong; winget is `Rahulnakmol.AgenticAyudha`, and a platform that takes a reverse-DNS identifier uses `com.rahulnakmol.agenticayudha`

## Finding

Nothing is on winget yet: the v0.1.0 submission microsoft/winget-pkgs#453928 was closed, and the v0.2.0 one, microsoft/winget-pkgs#454472 (`manifests/r/rahulnakmol/aayudha/0.2.0`), had passed validation with the CLA signed but under the old identifier. goreleaser v2.18.3 writes `Moniker` from the winget entry's `name` (one moniker per package) and has no moniker key; `winget install <query>` matches a case-insensitive substring of the name, ID, or moniker. aayu ships a plain CLI with no macOS app bundle, pkg installer, launchd or systemd unit, and no Linux package, so no field takes a reverse-DNS identifier today

## Implemented instead

`.goreleaser.yaml`'s winget entry: `package_identifier: Rahulnakmol.AgenticAyudha`, `publisher: Rahulnakmol`, `package_name: Agentic Ayudha`, `tags: [aayu, aayudha, cli, agents, software-delivery]`, and `name: aayudha` kept as the moniker, so `winget install aayudha` works and `winget install aayu` matches it as a substring (GitHub code search found no `aayu` in microsoft/winget-pkgs on 2026-10-17; a later package whose name, ID, or moniker contains it would make winget ask which one). The installed command is unchanged (`PortableCommandAlias: aayudha`, from the binary; the Scoop manifest also adds the `aayu` shim). `release.yml`'s winget job writes to `manifests/r/Rahulnakmol/AgenticAyudha/<version>`; `aayu self-update` points winget installs at `winget upgrade --id Rahulnakmol.AgenticAyudha`; `docs/getting-started.md` names the new ID. v0.2.0 was resubmitted as microsoft/winget-pkgs#454680 from `rahulnakmol/winget-pkgs`: the manifests are goreleaser's output for v0.2.0 with the new configuration, with the release's own installer URLs and SHA-256 (checked against its `checksums.txt`), and #454472 was closed with a comment pointing to it. `com.rahulnakmol.agenticayudha` is reserved in a `.goreleaser.yaml` comment and here, for an Apple codesign identifier, a macOS pkg or bundle ID, and Linux AppStream, Flatpak, or deb/rpm metadata if any is ever added. The Homebrew cask and the Scoop manifest keep the install name `aayudha`: they are install names, already published in `rahulnakmol/homebrew-tap` and `rahulnakmol/scoop-bucket`, and renaming them would break existing installs
