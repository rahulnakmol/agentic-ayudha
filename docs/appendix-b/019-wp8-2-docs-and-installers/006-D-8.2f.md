## Plan assumption

WP8.2 with D-8.2e; founder review of the live guide (2026-10-15): "Need strong storytelling, and then we have a technical deep dive"; a reader-facing summary per verb; the header "aayudha docs"

## Finding

The plan's registry has one `Summary` per verb, written for agents (SKILL.md and MCP descriptions), so the guide showed agent-facing text to new readers. The site's name came from the repository name. The founder asked for illustrative characters around real events; the real WP8.1 run had one human, so a two-person cast cannot honestly show a human pass. Several reference documents lag the code (the threat model's status column, the ledger README's `packs/` path), and the latest audit report predates the WP8.1 ships

## Implemented instead

Two tracks in the sidebar and on the home page. "The story": the prologue (`journey.md`), nine chapters (`journey-1-…` to `journey-9-…`), and an epilogue (`built-with-itself.md`), each chapter opening with a timed scene from the real run of 12 October, then what happened, what you do and what the agent does, what you learn, the verbs of that step, an "Under the hood" box, and a closing hook; the cast (Priya, Sam) is declared illustrative, the real run's single human is stated, and every time, number, and event comes from GitHub, the ledger, or Appendix B (the four capped pull requests and their findings, the contrast disagreement of D-8.1h, the plan bypasses of D-8.1a, the refused close brief of D-8.1c, the eval rounds of D-7.3g/h). "How it works": an overview and thirteen deep-dive pages (`how-*.md`), each with a brief-pipeline diagram, verbatim excerpts, invariants with their tests, links into the code, and honest-status notes where the code or this repository's setup falls short; they describe the code as it is where the reference documents lag. The registry gains `Reader`, one plain sentence per verb (a registry test requires it for every verb, one sentence, at most 160 characters, distinct from `Summary`; plumbing has none); `internal/verbs/gen` uses it in the verb map and in a generated `stage-verbs` region on each chapter; the verbs reference shows it as "In plain words". The site name is `design/brand.yaml`'s `name` ("aayudha docs"), falling back to the repository name plus " docs" (`tell.Brand.Name`, `TestSiteBuild`). Concepts gain "Under the hood" links; `docs/threat-model.md` joins the Reference group. The brand gains a scene and an "under the hood" colour pair, 27 pairs passing AA through `grill brand`.
