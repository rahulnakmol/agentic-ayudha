# D-8.2d

## Plan assumption

WP8.2: first `rolling` snapshot; brew/Scoop/winget after the stable decision

## Finding

The first rolling snapshots were promoted before WP8.2 (`rolling-2026-10-11`, `rolling-2026-10-12`, `rolling-2026-10-12.2`). Under D-0.4a the stable decision is an explicit stable-release request plus a green stable gate, which the orchestrator owns. `release.yml` already publishes the cask, the Scoop manifest, and the winget PR for a non-prerelease `v*` tag, and fails each job naming the missing secret until its repository and token exist (D-0.4d)

## Implemented instead

No promotion or `v*` tag is part of WP8.2. The founder creates, before the first stable tag: `rahulnakmol/homebrew-tap` with `HOMEBREW_TAP_TOKEN` in environment `release-homebrew`; `rahulnakmol/scoop-bucket` with `SCOOP_BUCKET_TOKEN` in `release-scoop`; and a fork `rahulnakmol/winget-pkgs` with `WINGET_TOKEN` (classic, `public_repo`) in `release-winget` (CONTRIBUTING.md, Release publishing setup). After v0.1.0, `gh workflow run installers.yml --ref dev` runs the release jobs
