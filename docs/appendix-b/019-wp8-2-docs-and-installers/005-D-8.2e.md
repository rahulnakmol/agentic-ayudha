# D-8.2e

## Plan assumption

WP8.2 with D-8.2b: the site is the repository's own docs; founder review (2026-10-14): "too technical; it has to be engaging, educative, encouraging", told as a journey that says when to use what

## Finding

The site had no reader path: README was the home page and every page was reference. The claims rule refuses a link to any work item that is not a proven Feature, so the WP8.1 story's stories, pull requests, Goal, and Release cannot be links. Goldmark renders with raw HTML omitted (no inline SVG), and images went to `raw.githubusercontent.com`. Before v0.1.0 the `install.sh` line 404s. The live site already had serious `scrollable-region-focusable` axe findings on wide tables and code blocks

## Implemented instead

A guide in `docs/guide/` goes in front of the reference: a home page (`docs/guide/README.md`, now `index.html`; README.md moves to `overview.html`, and stays the home page in a checkout without a guide), "Your first hour", a nine-page journey told with benefits-qa's real numbers, "When to use what", "Adopt at your own pace" (three levels with their keys, CI minutes, and model spend), and six concept pages; `GLOSSARY.md` joins the reference. Stories, pull requests, the Goal, and the Release are named as plain numbers; only the proven Features 127–129 are links. Pages say where benefits-qa did not use a verb (`experiment`, `readout`, `retro`, `evolve`, `tell`) and that its Result was measured on the seeded simulation before release. The registry gains a journey `Stage` per verb (`verbs.Stages`, every verb in exactly one, plumbing in none, tested), and `internal/verbs/gen` renders the 32-verb map into `docs/guide/when-to-use-what.md` (region `verb-map`). Diagrams are `docs/guide/img/*.diagram` sources rendered to SVG by brief's diagram renderer through a new `go generate` step (`internal/tell/gen`); the site serves images that exist in the checkout from its own copy (`tell.SiteMedia`). A block quote opening with a bold label ending in a colon (`> **Tip:** …`) renders as a styled callout, with the label kept as text. Narrow screens get a collapsed Menu instead of the sidebar; tables are keyboard-focusable and code wraps, which clears the scrollable-region findings. `design/brand.yaml` was written with `grill brand` (tone warm, direct, encouraging, plain; 22 AA pairs pass), so `tell` now takes its voice and avoid list from it. The install pages carry a "before the first release" note with `go install …@rolling-2026-10-12.4`. Verified: axe (agent-browser's axe-core 4.12.1) reports 0 violations of any impact on all 62 pages at 1280 px and 390 px, lychee is clean, and the site passes `tell`'s claims check. A first-time-reader review led to fixes: costs and fit on the home page, the simulated Result stated up front, and jargon explained where it first appears
