# D-8.2a

## Plan assumption

WP8.2: `tell docs` → GitHub Pages (the plan names no source branch)

## Finding

`dev` is the default branch, and the `github-pages` environment that Pages creates admits only the default branch until an admin adds a rule. `rolling` moves only on promotions, so docs built from it would trail the code that generates them, and neither branch has an installable artifact: `install.sh` installs only `v*` releases from `main`. Enabling Pages is a repository-admin call

## Implemented instead

`.github/workflows/pages.yml` builds on every push to `dev` (and on pull requests that touch Markdown, `internal/tell/`, `internal/verbs/`, or `skills/`, without deploying) and deploys `dev`'s build with `actions/deploy-pages`. Each page's header names the commit it was built from. Pages was enabled with `build_type: workflow`. Moving the site to `rolling` later is a trigger change plus a `github-pages` branch rule
