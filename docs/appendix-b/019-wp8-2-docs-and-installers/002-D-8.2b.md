# D-8.2b

## Plan assumption

WP8.2 with D-7.5a: the docs are `tell docs` copy; claims link only to Features with authoritative packs; `tell publish` is human-only

## Finding

D-7.5a's `tell docs` checks a draft the host writes; the plan does not say which pages the site carries or how a site reaches Pages. The repository's own Markdown is already reviewed copy, and a Pages deployment from CI writes nothing to the ledger. D-7.5a's check counted `#N` inside inline code (`[#12]` in the brief skill's citation format) as a claim, though GitHub renders no link there

## Implemented instead

New registry input `tell --site <dir>` (docs only; not with `--from` or `--publish`; the directory must be new or empty). It builds the site from the checkout: README (home, followed by the proven Features list), `docs/getting-started.md` (new: installing, `doctor`, and connecting Amp, Cursor, and Claude Code), CONTRIBUTING, SECURITY, CONSTRAINTS, LAYERS, and `docs/RACI.md` when present, plus a verbs reference generated from the registry and a page per embedded skill. Every page goes through `tell.Check` with the proven Features from the same rule; one problem refuses the whole site (exit 4, each problem named by source file and line) and nothing is written. Links to another page become relative links (heading anchors follow GitHub's rules, so `CONTRIBUTING.md#…` works); every other relative link resolves as GitHub resolves it and points at the built commit on GitHub; every outbound link carries the UTM tags (`utm_medium=docs`, campaign `docs-site` in the workflow). Goldmark (already a dependency) renders GFM with raw HTML omitted; one stylesheet, no scripts. `tell.Check` now skips inline code spans as CommonMark delimits them (a run of n backticks closed by the next run of exactly n), for claims, avoided words, and UTM tags alike. Deploying the site is not `tell --publish`: nothing is written to the ledger, and the pages are Markdown already merged to `dev`. Tests: `TestSiteBuild`, `TestTellDocsSite`, `TestCheckFences` (code spans), `TestCheckLeavesCodeSpanLinks`
