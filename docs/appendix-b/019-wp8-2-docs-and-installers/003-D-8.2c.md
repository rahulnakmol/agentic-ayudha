# D-8.2c

## Plan assumption

WP8.2 accept: `install.sh` on clean macOS/Linux/Windows VMs; `aayu doctor` passes

## Finding

No `v*` release exists until the orchestrator cuts v0.1.0, and `install.sh` accepts only `release.yml`-signed `v*` releases (WP0.4). The plan does not define "clean VM" or "passes". WP0.4 and D-0.4d name a Scoop manifest, not a PowerShell script, as the Windows package path; `install.sh` already supports Git Bash. GoReleaser cannot give a Scoop manifest or cask a second command name

## Implemented instead

`.github/workflows/installers.yml` (dispatchable, and run on pull requests that change `install.sh`, `.goreleaser.yaml`, or the workflow) uses fresh GitHub-hosted `ubuntu-latest`, `macos-latest`, and `windows-latest` runners as the clean machines. It builds a goreleaser snapshot signed keylessly by itself; on each OS `install.sh` must refuse a flipped byte (checksum) and the default `release.yml` identity (signature), then install the snapshot with `AAYU_CERT_IDENTITY_REGEXP` pinned to that run's exact identity, bootstrapping its pinned cosign where none is installed, into the default `~/.local/bin` (with the PATH hint when that directory is not on PATH). A new shell finds `aayu` and `aayudha` on PATH, `aayu version` names the snapshot, and `aayu doctor` in a fresh checkout with git and git-lfs installed exits 0 with no `FAIL` row and `PASS` for both. Windows runs `install.sh` in Git Bash, and the Scoop manifest in PowerShell: Scoop (installer pinned by commit and SHA-256) installs goreleaser's manifest from a local server, refuses the same manifest with a wrong hash, and its `aayu` shim runs `doctor`. When a `v*` release exists, the same three OSes run the documented `install.sh` from `main` with no overrides against the latest release, and Windows installs from the Scoop bucket once it is published. "Passes" means exit 0 and no `FAIL` row: `WARN` and `N/A` rows (no token, no host, optional tools) are what a new machine has. `release.yml`'s `scoop` job adds the `aayu` alias to the manifest with `jq`, the filter the workflow tests. The first Windows runs found two defects, both fixed here: Git Bash rewrote the backslashes of the identity regexp `install.sh` passes to the native `cosign.exe`, so no genuine release could have verified on Windows (`install.sh` now passes native paths with `cygpath -w` and turns MSYS argument conversion off for that call); and Windows has no zoneinfo, so `doctor` failed `config` on the default `[time] tz` (`internal/config` now embeds `time/tzdata`, about 450 KB). The Homebrew cask still links only `aayudha`, and Scoop and winget check only the archive's SHA-256 from their manifests; only `install.sh` checks the cosign signature
