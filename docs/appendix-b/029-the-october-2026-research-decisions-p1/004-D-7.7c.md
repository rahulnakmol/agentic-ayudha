# D-7.7c

## Plan assumption

S-7.7c; P4 of the research: "two independent stories" as evidence, safety findings excepted; recurrence "within 30 days after its evolve PR merged"

## Finding

Retro Feedback names a skill only in its title (skill `<name>`, the per-skill correction-rate finding), and its body is untrusted text. "Rewrite, not append" is a judgement; a diff's line counts are the only deterministic proxy. GitHub has no search for PRs by head-branch prefix. The founder's rule has no safety exception

## Implemented instead

**Two Feedback issues:** `aayu evolve --skill <s> --feedback <n>` lists the open retro Feedback with `needs:grill` (`acceptedFeedback`) and refuses (exit 4, nothing written) unless `#n` names skill `<s>` in its title and at least `EvolveMinFeedback` = 2 such issues exist; the PR body cites them all ("Evidence: #a, #b"). There is no safety exception: a safety problem is a Bug, not a skill evolution. `aayu evolve` without `--feedback` groups the list by skill and says which skills are ready, which are waiting (and for how many), and which Feedback names no skill. **Monthly cap:** it refuses when another PR whose head branch is `evolve/<s>-…` was opened in the last `EvolveCooldownDays` = 30 days (any state; PRs listed newest first until one is older); the evolve branch's own PR does not count, so a re-run still pushes. **Rewrite:** `aayu evolve` and CI's gate now pass `git diff --raw --numstat --no-renames`, which `ParseNameStatus` reads with line counts (a `--name-status` diff still parses, without them). The gate refuses a case whose skill diff (`skills/<s>/`, `evals/skills/<s>/`) adds lines but deletes none and deletes no file: "the skill diff only appends (N lines added, none removed or rewritten)". **Recurrence:** each retro lists the evolve PRs (head `evolve/<skill>-<n>`, merged into dev) merged in the `RecurrenceDays` = 30 days before the cursor, and the problem came back when a retro Feedback issue opened after the merge, or an unfiled finding of this window, names the same skill (a recurrence finding itself does not count). When it did, retro files "evolve did not hold: skill `<s>` (PR #p, Feedback #n) came back" with the `aayu install --pin` rollback. That title names the skill, so it counts toward the next evolve's evidence. The fake GitHub's PR list now honours `state` and `direction` and records `created_at`. Tests: `TestEvolveVerb` (one Feedback refused, a Feedback naming no skill or another skill refused, two accepted, a PR 10 days old blocks and 40 days old does not, the PR cites both), `TestEvolveGateCI` (an append-only skill diff is refused beside the same change as a rewrite, which passes), `TestRetroRecurrence` (came back by a later Feedback and by this window's finding; a Feedback before the merge, a recurrence finding, and a PR merged 35 days earlier do not count)
