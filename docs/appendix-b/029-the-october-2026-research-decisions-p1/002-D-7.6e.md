# D-7.6e

## Plan assumption

S-7.6e; P1 of the research: stage times from "ledger timestamps", touches from "human-only actions in the actions log", acted-on from posted finding IDs, escapes as PRs `inspect` passed that got a correction

## Finding

The actions log records the GitHub write, not the verb, and in solo mode almost every write carries identity `human` (agents run under the founder's token), so it cannot tell a person's touch from an agent's. Only stories built with `aayu build` have a first checkpoint (`build/<n>/state.json`): 6 of the 46 stories this repository delivered from 2026-10-01. A workflow run has no completion time in the API; `updated_at` is the last change. inspect keeps its state, including the IDs it posted inline (WP4.8b), in its replace-in-place PR comment, so PRs reviewed before inline comments record only their fix cycles. The founder named Bugs, not corrections, for escapes

## Implemented instead

`internal/audit/flow.go`, run by `aayu retro` only (`Source.Flow`). Per story delivered in the window: Ready is its first `status:ready` label (timeline); the first checkpoint the earliest `at` in its build record on the ledger; gate green the `updated_at` of the earliest successful `pull_request_target` run of `aayudha-merge-gate.yml` on the merge PR's final head SHA that completed by the merge; ship the merge (with or without `aayu ship`). Stages: queue (Ready → first checkpoint), build (→ gate green), human wait (→ ship), total (Ready → ship); each counts only stories with both ends and reports P50 and P90 by nearest rank, with "n of N stories". Touches: comments and reviews by a person on the story or its merge PR between Ready and ship (not a `…[bot]` or `[identity] bot_logins` login, not a comment carrying an `<!-- aayudha:` marker, not an approving review, which is ship's human pass), plus each later `status:ready` label and the PR's WP5.7 corrections other than changes-requested (already counted as a review); an agent writing as the founder without a marker still counts as a person. inspect: over PRs merged into dev in the window with an inspect comment, fix cycles, and each posted ID: dismissed when `inspect/dismissed.jsonl` on the ledger names it for that PR, open when the latest inspection still lists it, else acted on; the share is acted on ÷ posted. Escape rate: stories with a Bug (from the WP5.7 fetch: `type:bug` issues updated since the oldest of the 100 newest merged PRs) opened after the merge, before the cursor and within `[autonomy] correction_days`, whose body links the story or its merge PR (`#n`, `/pull/n`, `/issues/n`), and which that PR does not itself fix (a Bug filed first and fixed by the PR is not an escape). Change mix: the Conventional Commit type of every PR title merged into dev in the window, `other` when it has none. The GitHub inputs snapshot gains `gate_runs`, `bugs`, PR `head_sha`, a PR item's `inspect` state, and a comment's `aayu` flag, written by retro only, so audit's snapshots and golden are unchanged; the build records and dismissals come from the ledger at the recorded commit, so `retro --replay` is byte-identical. A retro report written before this change replays with the binary that wrote it (it has no Flow section). Test: `TestRetroFlow` (hand-computed and asymmetric: a 24-hour human wait beside a 1-hour one, three touches against a bot comment, a marker comment, and an approval that do not count, an escape against a Bug filed before the merge and one the PR fixes, a dismissal of the same finding ID on another PR, and a PR into `main` outside the mix; the numbers survive a snapshot round trip). First run on this repository (dry run, 2026-10-01 to 2026-10-16T00:00Z, 46 stories and bugs, 135 PRs): total Ready to ship P50 2.5 h, P90 6.4 h (45 stories); queue P50 1.6 h and build P50 1.2 h (6 stories); human wait P50 0.0 h, P90 0.1 h (12 stories: in solo mode the agent ships as soon as the gate is green); touches P50 1, P90 2; inspect reviewed 25 PRs with 22 fix cycles and recorded 1 posted finding, still open at merge (0 % acted on); escape rate 0 of 46; change mix feat 52 %, fix 27 %, docs 10 %, chore 4 %, test 4 %, ci 2 %, refactor 1 %
