# D-5.10a

## Plan assumption

Decision #324: `investigate` reads telemetry through read-only connectors or sanitised exports, with result limits; credentials stay out of the repository and CI

## Finding

A live connector per backend (Azure Monitor KQL, CloudWatch Logs Insights, Cloud Logging, Sentry, PostHog) needs a query API and a read-only role each; the WP7.2b adapters answer baselines and event pulls, not ad hoc trace and exception queries. The evidence rule (`seats.CheckGrounding`) knew no citation for a query result, so a note could not cite what it queried

## Implemented instead

**Exports first, live templates.** `aayu investigate <incident> --telemetry <dir>` reads a sanitised OpenTelemetry export with no network (`internal/production`: `traces.jsonl` in OTLP JSON, the OpenTelemetry Collector file exporter's format, root spans with their `exception` events; `logs.jsonl` JSON lines with `trace_id`; `deploys.jsonl` deploy markers), at most 64 MiB a file. Every query (`requests`, `errors`, `latency`, `exceptions`, `timeline`, `logs`, `deploys`, `trace`) is scoped to one service, names its window (at most 7 days) and its row limit (default 50, at most 500), redacts secret-shaped values and email addresses, and is logged per incident in `.aayudha/state/investigate/<n>/queries.jsonl` as `qN` (the same query on the same export keeps its ID), so a note cites `query qN`, a new citation kind of the evidence rule for every seat. For a live source the skill writes a fenced, bounded template (`kql`, `cwl`, `gcl`, `sentry`, `hogql`) for the person to run and export, and the note check refuses a template with no window or no limit; executing live queries through the `[integrations.*]` adapters is n/a until a later part. `investigate` refuses `--ci`: it runs in a person's own session, so no telemetry credential reaches product CI. The deployed revision comes from the deploy marker, else `service.version`; the grounding prints the commits and diff from the previous revision and each exception's innermost frame inside the repository at that revision, with its lines, and says when the deployed revision is not the branch head. `internal/telemetry` gains `NewFileExporter` (any resource, span events exported), which `examples/benefits-qa` uses: `api.Observe` makes each request a server span and a trace-linked JSON log line and recovers a panic into a 500 with an exception event; `deploy/deploy.sh` deploys a revision and writes the marker (`TestInvestigate`, `TestRun`, `TestQueryBounds`, `TestCheckInvestigation`)
