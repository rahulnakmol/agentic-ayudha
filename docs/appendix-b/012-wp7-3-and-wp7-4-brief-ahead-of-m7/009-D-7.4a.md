# D-7.4a

## Plan assumption

WP7.4: `*.diagram` → SVG (static + interactive), charts from snapshots with their query, illustrations via Painter/Gemini labelled as such, annotated screens from packs; alt text states the takeaway. Accept: every chart carries a query and re-running the query reproduces the chart data (golden)

## Finding

The plan names no diagram format. Image generation is a host tool (Painter) or a model, and CI must not call an image model. `measure`'s query engine returns integers only. Whether alt text "states the takeaway" is not decidable by rule

## Implemented instead

Visuals are fenced blocks (`diagram`, `chart`, `illustration`, `screen`): `key: value` header lines, then a body. `alt` is required on each: a sentence of at least four words ending in a full stop that does not open by naming the medium ("Diagram of …"); the judge and the adversarial pass read the rest. `*.diagram` (inline, or `src:` a file beside the draft): lines `id: Label \| note`, `a -> b: label`, `title:`, `direction: right\|down`; at most 40 nodes and 80 edges; layered layout (longest-path ranks, barycentre order), and a left-to-right flow wider than 760 px turns top-to-bottom unless a direction is set. It is written as a static SVG image file beside the page (`role="img"`, the alt as title, the edges in words as description) and drawn inline as an interactive group: nodes are focusable buttons, and focus, hover, click, Enter, or Space highlights a node with its neighbours and shows its note in a live region (Escape clears), with a "Diagram as text" list. Charts: `snapshot: D1` (a snapshot the Result names, its SHA-256 checked), a body of one read-only `SELECT` or `WITH` statement (no `ATTACH`, `PRAGMA`, or writes; opened `mode=ro` with `query_only`; at most 200 rows and 8 columns; integers, reals, and text, through `database/sql` on `modernc.org/sqlite`), `x`, `y`, and `kind: bar\|line`; drawn as an SVG chart with the data table, the snapshot and its hash, and the query in the page, and the rows in the manifest. Illustrations: `src` is an image the host made with Painter or Gemini and `generator` names it (required); PNG, JPEG, WebP, or GIF up to 5 MiB, Mobbin-origin images refused (WP6.4); captioned "Generated illustration made with … ; it explains, it is not evidence". The binary never calls an image model, and the tests use a labelled fixture image. Screens: `pack: P1` and `artifact:` a screenshot of that pack, read through the proof store with its SHA-256 checked; body lines `x,y: note` (percent) become numbered marks with a notes list. Tests: `TestChartGolden` (the acquisition cohorts 3, 2, 1 in weeks 0, 1, 3, worked out by hand from the WP7.2 fixture exports; re-running the stored query on the snapshot gives the same rows; write statements are refused) and `TestRenderSample`
