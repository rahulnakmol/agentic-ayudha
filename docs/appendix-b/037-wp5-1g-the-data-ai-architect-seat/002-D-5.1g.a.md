# D-5.1g.a

## Plan assumption

The evidence rule (WP5.1b): "a claim you cannot cite is marked unverified"

## Finding

`seats.CheckGroundingWith` refused every unit with a claim cue and no citation, including the ones the rule itself asks the twin to mark, so a chart note's defaults ("Assumption: the latency budget is two seconds") could not be written honestly

## Implemented instead

A unit that starts `Assumption:` or `Unverified:` (optionally bold) states nothing as fact and needs no citation; any citation in it is still resolved against the grounding. `TestCheckGrounding` holds both sides (a marked assumption passes, an unmarked one fails, a marked one citing an invented issue fails). This relaxes the check for every seat; no recorded retro, proof, or decide case changes verdict
