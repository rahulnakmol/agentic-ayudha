# D-4.8c.5

## Plan assumption

Decision 2: (a) "no test for X" notes become per-criterion verdicts and are not raised on `_test` files; (b) a sealed coverage manifest. Decision 3: weakened checks flagged. P2: count tests that only restate the code

## Finding

The verification research measured all 8 inspect false positives as P2 "no test for …" findings on `*_test.go` files

## Implemented instead

\#216: the filter drops `test-gap` (a test-category finding on a test file) and the new `test-value` category; both are counted in the summary, never posted. `TestGapVerdicts`: a P0/P1 gap makes its criterion `unmet`, a lesser one turns `met` into `unclear`, one with no criterion is a note. `inspect.Seal` lists every changed file as reviewed, skipped (generated, deleted), or unreviewed (past the 120 kB prompt cap, or not in a reply's `reviewed`), with a SHA-256; an unreviewed file turns `merge` into `fix`. `inspect.Weakened` flags, from the diff alone: fewer assertions or a new skip in a test file, fewer CI steps, `continue-on-error`, `if: false`, `\|\| true`, and a threshold moved in its loose direction; the inspect comment and the proof comment show them; nothing blocks on them. Nothing from Open Code Review is vendored or called
