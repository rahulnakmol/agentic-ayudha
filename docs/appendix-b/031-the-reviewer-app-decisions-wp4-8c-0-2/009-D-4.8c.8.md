# D-4.8c.8

## Plan assumption

P3: when a required check fails, aayu @-mentions the builder agent to fix it, within the 2-round cap

## Finding

The builder of a delegated PR is reached through its session (Cursor run, Amp thread, Claude cloud session, Codex task, or the local CLI), not a PR mention: Codex's task mode needs an environment, and Amp has no mention

## Implemented instead

\#231: a `delegate` sync that finds a failed required check on the head (`aayudha/merge-gate`, `aayudha/pack`, `[verify] upstream_checks`; never `protected-paths` or `aayudha/inspect`) sends one follow-up per head through the receiver's channel, with each check's link and the last 60 lines of its job log, redacted and fenced as data. Rounds share inspect's two-cycle cap, then a human is paged. `build --resume` (no delegation) is unchanged: the agent running it reads the checks itself
