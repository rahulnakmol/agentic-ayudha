# D-4.8c.6

## Plan assumption

P6: a deterministic risk line on the proof comment

## Finding

A "protected path" in a product repository is what CODEOWNERS names; a catch-all owner names every file

## Implemented instead

\#228: `inspect.RiskOf`, run by the pack job on the PR diff with the base checkout's layers, never-layers, and CODEOWNERS: high for a never-layer footprint, a specific CODEOWNERS rule, a dependency manifest with added lines, or a migration path; medium for 3+ layers, more than 400 changed lines, or more than 20 files; low otherwise. The proof comment opens with the tier, the reasons, and up to five files to read first; it approves nothing
