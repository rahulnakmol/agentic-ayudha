# D-4.2b.d

## Plan assumption

D1 and WP1.4: `init --identity` replaces the ledger ruleset's admin bypass with the bot App; WP2.5: `.lfsconfig` for media on private ledgers

## Finding

Ship writes the ledger under the human's identity, so replacing the admin bypass would lock ship out

## Implemented instead

`ledgerBypassApp` keeps the repository admin role and adds the App beside it. Only a repository admin could ship (the ledger push was refused otherwise) until D-4.2b.h widened it to the write role. `init` still writes the LFS attributes on a private ledger, now for design and baseline media only; the public-repository config scaffold describes the bucket as optional
