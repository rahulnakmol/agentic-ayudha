# D-4.2b.c

## Plan assumption

WP4.2, D-4.2a, D-7.1b, D-7.2b.2a: `proof purge`, tombstones, the `proof-purge` default loop, and media delete

## Finding

Nothing writes media that need purging any more: the artifact expires on its own, and the ledger copy holds text only. A bucket costs little to keep (push, get, verify, lifecycle are separate from purge)

## Implemented instead

Removed: `proof purge`, `proof.Purge`, `Media.Delete` (S3, Azure Blob, GCS), `loops.Defaults` and the `secrets` loop key, `loops/proof-purge.toml` and its Amp and Cursor renders, tombstones on new packs, the LFS media path of `proof push`. Kept: `[proof] media` as opt-in for longer retention (`proof push --media` without a bucket now exits 4 on every repository); `proof verify`, `get`, and `list` still read 0.1 packs, including tombstoned ones and `store: lfs` (`TestVerifyReadsPacksFromBefore02`); `audit` reads the same `[proof]` keys, so `TestAuditReplaysRecordedReports` stays byte-identical. New `proof.VerifyLocal` checks a local pack's hashes (a local pack has `store: none`, which plain `Verify` skipped)
