# D-4.2b.g

## Plan assumption

V3: media never public; D-4.2b.b: a public repository's run artifact can be downloaded by any signed-in GitHub user

## Finding

Founder decision (2026-10-15, relayed by the orchestrating thread): accepted

## Implemented instead

On a public repository, proof media in the merge gate's `aayudha-pack` artifact are readable by any signed-in GitHub user until the artifact expires, at most 90 days. This is where V3's "no public media" no longer holds; its other intent (no media in git, bounded retention) stands. No code change: captures still use `[verify] seed` data and the redaction pass (WP4.5), and a team that needs less exposure deletes the artifact on GitHub or keeps the repository private. Recorded in the threat model (T14)
