# D-4.2b.f

## Plan assumption

S-4.2b: prove it end to end on a scratch repository: a PR gets the artifact and the comment, ship refuses a pack from another SHA or a hand-uploaded artifact, and ship succeeds on the real one

## Finding

GitHub has no API to attach an artifact to a run from outside it, so "hand-uploaded" means an artifact uploaded by a workflow the PR controls: the PR's own copy of the gate file, run on `pull_request`. The scratch repository has no model key, so `aayudha/inspect` cannot review

## Implemented instead
