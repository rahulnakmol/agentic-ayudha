# D-2.2a

## Plan assumption

WP2.2: "forms generated from schema"; accept "`init --dry-run` lists labels/types"

## Finding

`init` itself is WP2.5. GitHub rejects a form whose `type:` names an issue type the owner does not have, and personal accounts have none

## Implemented instead

`go generate` writes one form per type to `work-items/forms/aayudha-<type>.yml` (the `aayudha-` prefix keeps them apart from a product's own templates); `init` installs them under `.github/ISSUE_TEMPLATE/` and adds `type:` only on organizations. Forms carry the Create fields (required) and, for non-intake types, the Ready fields (optional until `ready`); intake forms add the `intake` label. The WP2.2 binary implements only `init --dry-run`: it plans the label and issue-type creations through `actions` (all `planned`, zero writes) and lists them; without `--dry-run` it exits 2 until WP2.5. Forms are checked against GitHub's form rules in `TestFormsPassGitHubFormSchema` and were validated once against the SchemaStore `github-issue-forms` JSON Schema
