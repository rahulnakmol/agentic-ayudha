# D-2.3a

## Plan assumption

WP2.3: go-github and githubv4, ETag cache, primary and secondary rate limits with serialized bulk writes, pagination, call budget per verb

## Finding

go-github v91+ requires Go 1.26 (D5). Creating and deleting a repository needs rights the founder's day-to-day fine-grained token lacks. The plan does not say how "every external write goes through `internal/actions`" is enforced for API calls

## Implemented instead

`github.com/google/go-github/v90` (BSD-3-Clause) and `github.com/shurcooL/githubv4` (MIT, GraphQL for Projects v2 only), with `go-querystring` and `shurcooL/graphql` (`golang.org/x/oauth2`, used only by githubv4's own tests, is held at v0.36.0 because v0.37 requires Go 1.26). One transport stack in `internal/github`: a mutating request without the context mark that only `Client.Write` (a wrapper over `actions.Do`) sets fails with `ErrUnlogged` before it leaves the process, so a write outside `actions` is impossible rather than merely discouraged; the action's capability is checked per request; writes are serialized with a 1 s gap; 403/429 responses are retried up to 3 times after `Retry-After`, the primary reset, or one minute for an unlabelled secondary limit, and fail at once when the wait exceeds 2 minutes; a per-run in-memory ETag cache revalidates repeated GETs (304s are counted as `not_modified`); a call budget (default 2000 per run, including 304s) stops a run with `ErrBudget`; `Stats` is what verbs report in `--json`. GitHub and network errors map to exit 5. Live tests create `aayu-scratch-*` repositories with `AAYU_LIVE_ADMIN_TOKEN` when set (the founder's admin token) and delete them; `TestLive` with `AAYU_RECORD=1` rewrites the recording that `TestRecordedContract` replays request by request
