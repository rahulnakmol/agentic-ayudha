# D-0.4c

## Plan assumption

WP0.4: path filters

## Finding

A workflow-level `paths:` filter leaves a required check pending forever; a job skipped by `if:` reports success

## Implemented instead

Path filters are job conditions fed by a `changes` job (`lint`, `docs`, `release-snapshot`). `build`, `generate-drift`, `security`, and `commits` always run on PRs; pushes and dispatches run everything. Fork PRs skip `release-snapshot` because they cannot mint an OIDC token for keyless signing
