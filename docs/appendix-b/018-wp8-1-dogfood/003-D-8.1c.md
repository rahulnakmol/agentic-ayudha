# D-8.1c

## Plan assumption

Ground rule 5: `review` lane A and the `brief` adversarial pass call a model directly from the binary, where the person running the verb holds the key

## Finding

aayudha's only model key is the `ai-gateway` environment's secret, which admits dev, rolling, and main. Neither the founder's machine nor the agent's orb holds a key, and the orb's other gateway variables belong to another organisation and are not used

## Implemented instead

`aayudha-model-lanes.yml`, dispatch only, from dev: `verb=review pr=<n>` checks out the PR head, builds the example (no PR code runs as the runner user), runs it as `nobody` so it cannot read the key holder's environment, and runs `aayudha review <n> --ci` (lane A through the gateway, lane B with the base branch's floor tools); the critique and captures are the run's artifact and the PR gets review's replace-in-place comment. `verb=brief subject=<n> register purpose draft=<base64>` runs `aayudha brief … --ci` on dev with the gateway (the adversarial pass) and Playwright (the page's axe check); the HTML, manifest, draft, and output are the run's artifact. Only the step that runs the verb sees the secret
