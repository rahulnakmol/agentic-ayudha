# D-1.6b

## Plan assumption

WP1.6 and D-1.6a: the `[budget]` breaker trips at `per_story_usd` or `per_day_usd`

## Finding

Bug #177: `Breaker.Seed` was never called, so every `aayu` process started at zero and the limits bounded one process's spend; only the pause file carried a trip across processes. The actions log is per clone (`.aayudha/telemetry/actions.jsonl`, shared by its worktrees), and a CI run starts from a fresh clone

## Implemented instead

`Env.Gateway` seeds the breaker from the clone's actions log through `Breaker.SeedLog` before any call: every logged record with a cost counts toward its story and its local day in `[time] tz`, so per-day counts today's records and per-story the story's. A CI run's breaker still sees only that run's spend, and a host's own model spend inside a skill stays invisible to it (docs/guide/how-models.md). Tested by `TestBudgetBreakerAcrossProcesses` (two `aayu triage` child processes, each the test binary run as the CLI, sharing one state directory and calling a fake model endpoint through `[models.gateway]` that reports each call's cost: 0.60 + 0.60 USD on one day trips `per_day_usd = 1` with exit 6, the pause file, and one page in the `file` outbox; on one story it trips `per_story_usd = 1`; 0.90 USD yesterday does not count today) and the `TestBudgetBreaker` cases for a missing log, a malformed one, and one that cannot be read (a directory)
