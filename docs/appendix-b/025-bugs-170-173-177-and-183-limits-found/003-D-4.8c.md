# D-4.8c

## Plan assumption

WP4.8, D-4.8a, and WP4.8b: `inspect` reviews with a model whose family ≠ the builder's; the builder's family from the delegation record, else the pack's `model` (the `Aayudha-Model` trailer), else the build lane of the pack's host

## Finding

Bug #171: the trailer is written into the PR's own commits, so for every PR not delegated the different-family rule rested on what the builder said about itself, and a hand-made commit can carry any trailer. The actions log is per clone and absent from the merge gate's fresh checkout. A host-managed lane (Amp) records no model. The first fix, written before inspect v2 (#186) merged, was reworked onto it

## Implemented instead

`build` writes each checkpoint's model into its ledger record (`CheckpointRecord.Model`). `inspect` lists the PR's commits and calls `inspect.BuilderOf` with the delegation record and the checkpoint models: the family is known only when a delegation covers the PR, or a checkpoint names a model family for every commit, the records name one family, and the trailer, if any, agrees. Otherwise it is unknown, and the records', the trailer's, and (with no record) the build lane's families are candidates; `reviewerModels` (WP4.8b) takes the candidates, so the first reviewer and the peer are each of none of them, or inspect exits 4. The verdict's first note names the family and its source, marks the trailer "self-reported, unverified", and calls a family from a build record "attributed, not verified": the record holds what `build` resolved (`AAYU_MODEL` or the lane), and without a bot App the founder's token, which agents use here, can write the ledger. inspect's first review of this fix (cycle 1) found both: an agreeing builder-controlled record presented as verified, and a checkpoint without a model counted as covering its commit. Tested by `TestInspectBuilderFamily` (a trailer naming anthropic over a record naming openai is reviewed by `grok-4.7`; no record names the lane's family; an honest PR is reviewed by `gpt-6.1-sol` with the record as source), `TestBuilderOf` (partial and model-less records, two families, delegation, a trailer contradicting a delegation), and the checkpoint model assertion in `TestBuildTextDryRunPlanAndBudget`
