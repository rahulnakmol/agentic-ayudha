## Implemented instead

Evidence only: no product change. Defects to route, beyond D-5.5c.11's five. (1) `aayu init` on a private personal repository on GitHub Free stops at the ruleset step (403 "Upgrade to GitHub Pro or make this repository public"), and `--resume` retries the same step, so `config` and `agents` never run. The test marked the step done in `.aayudha/state.json`. (2) On Codex, a vague ask in plain words never reaches the gate, and the `AGENTS.md` sections that init and install write do not tell an agent to assess a request first. (3) On Codex, verdict `unpack` did not stop the agent. Nothing in `ready` or `build` holds a story for the human's confirmation, so it went from `ready 4` to PR #5 unasked. (4) Codex 0.162.1 runs plugin and project hooks only after the person trusts them (`/hooks`). Neither install nor `hosts/README.md` says so. Until then no guard rail exists on Codex, because `ship` itself does not refuse an agent. (5) `install --loops` says "`aayu init --gates` adds the defaults", but `init --gates` writes no `loops/*.toml`, so the suggested next step is a dead end. (6) The hook's refusal of a human-only verb ends `next: aayu resume`, which is the budget breaker's verb and is itself human-only. (7) With the plugin and `install` both present, Claude Code runs both PreToolUse hooks and lists two aayudha MCP servers. The project one stays "Pending approval" although install wrote `enabledMcpjsonServers` (the docs say to use one). (8) From a fresh repository, a vague ask needs a Goal, an Initiative, and a Feature before its Story. A Goal's Metric must be a snapshot name or a provider query, so the agent filed `north_star` as a stand-in. `grill` rejects `status:in-progress`, and no verb sets it. (9) While `build` held a lease and PR #5 was open, `status` counted Story #4 as Ready, and #4 kept `status:ready`. (10) A Story titled "Story: …" yields the PR title `feat: story: …` and the branch `story/4-story-…`. The scratch repository, the plugin installs, and the throwaway configuration were removed
