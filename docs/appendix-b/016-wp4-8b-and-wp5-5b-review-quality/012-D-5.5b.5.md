# D-5.5b.5

## Plan assumption

WP5.5b: environments generated from one source and kept in sync; a doctor check per receiver

## Finding

Codex cloud environments are defined only in its UI; Cursor reads `.cursor/environment.json` from the default branch; Amp reads `.agents/setup`; claude-code-action runs in the repository's workflow (research §6)

## Implemented instead

`.agents/setup` is the source. `aayu doctor --fix` writes `.cursor/environment.json` (`install: bash .agents/setup`; other keys kept), committed here for `dev`. The `delegate-env` check reports, per receiver: source executable and its Go pin not older than `go.mod`; Amp native; Cursor drift; Codex manual (the exact Install script, internet preset, and `[delegate] codex_env`); Claude, whether a claude-code-action workflow runs `.agents/setup` first. aayu writes no `.github/` file for it. A repository without `.agents/setup` passes with "not set up"
