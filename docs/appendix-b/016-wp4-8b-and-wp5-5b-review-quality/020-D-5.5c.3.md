# D-5.5c.3

## Plan assumption

WP5.5c: prove every host loads the commands

## Finding

Claude Code (`claude plugin details`), Codex (`codex debug prompt-input`), and Amp (`amp plugins list`) list a plugin's commands without signing in. The Cursor CLI (2026.10.14) has no headless way to list a plugin's commands, and every run that would show them needs a sign-in

## Implemented instead

`TestHostPluginsLoad` runs live on Claude Code 2.1.301, Codex 0.163.0, and Amp in the orb. Cursor's manifest is checked only against Cursor's documented schema (`TestPluginManifests`), so Cursor as a host is proven by golden files only until a signed-in Cursor CLI runs the test. Superseded in part by D-3.2b.q: even signed in, the Cursor CLI cannot list a plugin's skills or commands, so the test covers none of Cursor; its MCP server and hook are proven live only
