# D-4.8b.7

## Plan assumption

WP4.8b/WP5.5b: delegated PRs reviewed in peer mode by default (`[inspect] delegated_mode = "peer"`)

## Finding

The reviewer eval (run 38690306973, D-4.8b.6) measured general mode's precision at 0.73 against peer's 0.46, with recall 0.95 against 1.00, at about a fifth of peer's cost

## Implemented instead

Founder decision, 2026-10-15: `[inspect] delegated_mode = "general"` in `internal/config/defaults.toml`, so delegated PRs get one reviewer of a family different from the builder's, like every other PR. Peer stays available per run with `inspect --mode peer` or per repository with `delegated_mode = "peer"`
