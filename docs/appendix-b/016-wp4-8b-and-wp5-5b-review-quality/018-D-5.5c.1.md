# D-5.5c.1

## Plan assumption

WP5.5b: the four hand-off commands load in the Claude Code and Codex plugin

## Finding

Codex 0.163.0 drops a plugin command whose body uses `$ARGUMENTS`, `$<n>`, `{{…}}`, `` !` ``, or an `@mention` (codex-rs `core-plugins/src/command_migration.rs`), so before this change Codex offered only `home` and `next`; Claude Code and Cursor append the user's text when a command does not use `$ARGUMENTS`

## Implemented instead

The command sources use no `$ARGUMENTS`: the host appends what the user typed (Amp's plugin asks for it when the command has an `argument-hint` and appends it as `ARGUMENTS:`). `TestPluginManifests` fails on any of Codex's refused tokens; `TestHostPluginsLoad` checks that Codex lists `aayudha:source-command-{claude,cursor,amp}`
