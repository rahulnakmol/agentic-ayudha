# D-5.5c.2

## Plan assumption

WP5.5c: no host offers a hand-off to itself

## Finding

Claude Code and Codex shared one manifest, which loaded the whole `hosts/commands/` directory, so Claude Code offered `/aayudha:claude` and Codex `codex`. Codex reads `.codex-plugin/plugin.json` before `.claude-plugin/plugin.json`, and Cursor reads `.cursor-plugin/plugin.json` first. Claude Code 2.1.301 lists no command given as a single file in `commands`, though its docs allow one, but it does load several directories

## Implemented instead

The sources move to `hosts/commands/common/` (`home`, `next`) and `hosts/commands/<agent>/<agent>.md`. Three manifests (`.claude-plugin`, `.codex-plugin`, `.cursor-plugin`) each list `common/` and every agent's directory except their own, with hooks for their host (`hosts/codex/hooks.json`, `hosts/cursor/hooks.json` in Cursor's format), and `.cursor-plugin/marketplace.json` lists the plugin. `install --host amp` gives the Amp plugin every command except `amp`. The pre-tool hook already allowed `aayu ready`, `grill --assess`, `build --delegate`, and `status --work`; a test now holds that on all four hosts
