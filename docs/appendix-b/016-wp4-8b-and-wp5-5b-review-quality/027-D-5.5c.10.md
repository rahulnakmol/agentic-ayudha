# D-5.5c.10

## Plan assumption

WP5.5c: if the cloud environment is missing or stale, set it up and verify it, then hand off; detect which CLIs and apps are installed (the agent-environments work owns both)

## Finding

`agentenv` (PR #240) provides `Detect` (offline: PATH, version, each CLI's own sign-in status, aayu's secret store, the recorded Amp project) and `Ensure` (regenerate and verify in a clean container, about 4–6 minutes for this repository with Docker; `ErrNotLanded` when the verified files are not on the default branch)

## Implemented instead

`build --delegate` decides cloud availability from `Detect` (Codex: a ChatGPT login and `[delegate] codex_env`; Cursor: its API key; Claude Code: a claude.ai sign-in; Amp: signed in with a recorded project) and local readiness from the CLI being installed and signed in, or holding its own key. The missing-receiver message prints `Detect`'s install and sign-in commands and cloud detail verbatim. A fresh cloud hand-off calls `Ensure` for the receiver first: a failure, or `ErrNotLanded` with its exact git command, stops the hand-off (exit 4) and offers `--local`. Syncs do not re-run it. Tests inject `Detect`'s probes and `Ensure`
