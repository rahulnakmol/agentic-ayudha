# D-5.5b.4

## Plan assumption

WP5.5b: cloud by default, local fallback in an aayu worktree with a scrubbed environment and no merge rights

## Finding

A local CLI runs as the user, whose HOME holds git and gh credentials

## Implemented instead

`--local`, or a receiver whose cloud agent is not connected (no Cursor key, no `codex` with `[delegate] codex_env`, no claude-code-action workflow, no `amp` with `AMP_API_KEY`), runs `codex exec --sandbox workspace-write`, `cursor-agent -p --force`, `claude -p --permission-mode acceptEdits`, or `amp -x` in `.aayudha/worktrees/<n>-<agent>`, under `[delegate] local_timeout_minutes`. Its environment keeps the toolchain variables and the receiver's own key only (no `GITHUB_*`, `GH_*`, `AAYU_*`, or other secret-named variable), with an empty `GH_CONFIG_DIR`, no git credential helper, and `GIT_SSH_COMMAND=false`, so it cannot push; aayu commits (`Aayudha-Delegate: <r>`), verifies, pushes, and opens the PR. Receivers in the cloud push through their own GitHub Apps; none can merge: `dev`'s rules and `ship`'s human pass hold
