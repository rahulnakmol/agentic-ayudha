# D-4.8b.1

## Plan assumption

WP4.8b: retrieve the changed symbols, their callers, related tests, and the `LAYERS.md` footprint

## Finding

The merge gate's `aayudha/inspect` job holds the model key and must never run or check out PR code (D-4.8a); a whole-repository symbol graph needs every file of the head

## Implemented instead

`inspect.BuildContext` reads the head through the contents API at its SHA (`headSource`): each changed directory is an area; Go files are parsed (never built) for the changed declarations, their call sites in the same package, and the `Test*`/`Fuzz*`/`Benchmark*`/`Example*` functions that name them; other languages use the diff's hunk headers and sibling test files. At most 40 files and 200 kB each are read, 40 kB of context reaches the prompt, and a new file's source is not repeated (the diff shows it). Each area's plan lists files, layers, changed symbols, callers, related tests, whether a test changed, generated files, and risks: one per touched layer with a known risk (L02, L04, L06, L07, L09) and one per pattern over the added lines (concurrency, external input, secrets, destructive operations, ignored errors, boundaries), plus "no test changed in this area". Identifiers in the plan are cut to identifier characters; the retrieved code is an `<untrusted source="code-context">` block. Callers outside the package are not found (later: a repository index)
