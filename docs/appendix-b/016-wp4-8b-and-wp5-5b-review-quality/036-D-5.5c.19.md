# D-5.5c.19

## Plan assumption

WP5.5: the branch, commits, and PR title come from the story's title

## Finding

Defect from the megaman run (D-5.5c.12 problem 10): the issue forms start every title with its type and a colon (`Story:`), so a Story titled "Story: …" got the PR title `feat: story: …` and the branch `story/4-story-…`

## Implemented instead

`workitems.BareTitle` drops a leading `<Type>:` of any work-item type, in any case (a title that is only the prefix keeps it), and `build` uses it for the branch, the checkpoint commits, the PR title, and the delegation brief. Regression test: `TestBuildDropsTheTypePrefix`
