# D-5.5c.15

## Plan assumption

WP5.5c: aayu reports what the receiver says it proved (D-5.5c.6)

## Finding

Defect from the megaman run (D-5.5c.11 problem 3): `delegate.Proved` took the first `## What I proved` in the CLI's combined output, and `codex exec` echoes the prompt first, so for Codex it returned the prompt's own template ("1. proved: <how you checked …>")

## Implemented instead

`Proved(text, echoed)` removes the prompt the receiver was given, counts only a heading at the start of a line, and takes the last one. The header and echo in `internal/delegate/testdata/codex/exec-local.txt` are as codex-cli 0.163.0 printed them in an orb; the answer is synthetic. Regression test: `TestProved`
