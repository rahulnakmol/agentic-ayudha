# D-5.5c.8

## Plan assumption

WP5.5b: a receiver whose cloud agent is not connected falls back to its local CLI

## Finding

Founder rule (2026-10-16): cloud is the default and the local CLI is an explicit switch the user chooses; a missing receiver is said plainly with its install and sign-in steps, and a connected route is offered

## Implemented instead

`build --delegate <r>` without `--local` refuses (exit 4) when `r`'s cloud agent is not connected, and says what is missing for `r` (cloud agent, CLI) and what is available: `--local` when its CLI is installed, `--delegate <x>` for every connected cloud agent. `--local` without the CLI says so and offers the cloud agent or another installed CLI. `auto` picks among cloud agents only, or among local CLIs only with `--local`. A sync keeps its hand-off's mode. aayu never installs or signs in for the user. The install and sign-in commands per receiver come from `agentenv.Detect` (D-5.5c.10)
