# D-5.5c.9

## Plan assumption

WP5.5c: a goal in words goes through grill's vagueness gate before any hand-off

## Finding

The gate (WP5.8, PR #226) keeps `aayu grill story --assess --idea "<goal>" --json` as its entry point and adds `gate.verdict` (`unpack` or `pass`) with `gate.reasons`

## Implemented instead

The four hand-off commands run the assessment, follow grill's gate on `unpack` (each reason named, the riskiest question first, a read-back of done before anything is created), create the story from the user's own words on `pass`, and hand off only after `aayu ready n` passes. `build --delegate` refuses a story that is not Ready, so the CLI enforces the gate whatever a host's model does
