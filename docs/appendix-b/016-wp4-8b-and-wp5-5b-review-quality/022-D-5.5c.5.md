# D-5.5c.5

## Plan assumption

WP5.5b: the local receiver keeps its own key

## Finding

`OPENAI_API_KEY` and `ANTHROPIC_API_KEY` are generic provider variables that often hold a model gateway's credential; `codex exec` reads `CODEX_API_KEY` (or its saved login), and Claude Code's print mode prefers `ANTHROPIC_API_KEY` over the user's subscription when it is set

## Implemented instead

The scrubbed environment passes only variables that belong to the receiver's own CLI: `CODEX_API_KEY`, `CURSOR_API_KEY`, `CLAUDE_CODE_OAUTH_TOKEN`, `AMP_API_KEY`. Provider keys and base URLs never pass, so a receiver runs on its user's own sign-in and never on a gateway credential
