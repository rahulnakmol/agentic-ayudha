# D-5.5c.14

## Plan assumption

WP4.4, WP5.5c: the evidence map names tests the merge gate can find

## Finding

Defect from the megaman run (D-5.5c.11 problem 2): the brief's placeholder `"<package path>:<TestName>"` led the receiver to write `./mathx:TestSum/positive`, and `verify.TestEvidence` matched neither the `./` path nor the subtest, so it reported "did not pass in this run" for tests that passed

## Implemented instead

`TestEvidence` accepts a package as an import path or a directory from the root (`./mathx`, `.` for the root) and a test as a top-level name or a subtest, which covers its own subtests but not its siblings. The brief names both shapes and its placeholder is `"./<package dir>:<TestName>"`. Regression test: `TestTestEvidence` (a `./` subtest that passed, and a sibling subtest whose child failed)
