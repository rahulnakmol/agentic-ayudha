## Implemented instead

Evidence only: no product change, and `ScrubEnv` is unchanged. Codex's local receiver counts as proven once a host with a working sandbox (megaman after `apt install bubblewrap`) passes `TestLiveLocalReceivers/codex` and a `--delegate codex --local` hand-off. The scratch repository and the throwaway configuration were deleted. The run found five open problems, not fixed here. (1) `LocalArgs` gives Claude Code `--permission-mode acceptEdits`, which denies Bash in print mode, so a local Claude receiver cannot run the tests that D-5.5c.6 asks it to verify with. (2) The brief's evidence placeholder `"<package path>:<TestName>"` led the receiver to write `./mathx:TestSum/positive`. `verify.TestEvidence` matches neither a `./` path nor a subtest, so it reported "did not pass in this run" for tests that passed. (3) `delegate.Proved` takes the first `## What I proved` in the CLI's combined output. `codex exec` echoes the prompt, so for Codex it returns the brief's own instruction (the live test logged `1. proved: <how you checked …>`). (4) A local receiver that exits 0 with no change ends `build` with exit 4 and drops the receiver's final message and the delegation state, so Codex's "not proved" report was lost. (5) A host gap, not aayu's: megaman has no semgrep, gitleaks, or osv-scanner, so `verify`'s sast, secrets, and deps floors block there
