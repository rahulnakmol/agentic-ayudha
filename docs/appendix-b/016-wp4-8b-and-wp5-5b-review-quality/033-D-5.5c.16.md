# D-5.5c.16

## Plan assumption

WP5.5c: the calling host reports the receiver's result (D-5.5c.6)

## Finding

Defect from the megaman run (D-5.5c.11 problem 4, D-5.5c.12 Claude Code → Codex): a local receiver that exited 0 with no change ended `build` with "nothing to commit yet" (exit 4), and its final message and the delegation state were dropped, so Codex's "not proved" report was lost

## Implemented instead

`build --delegate --local` with no change records the hand-off as failed ("the local codex run changed nothing") with the receiver's report on the ledger and the story comment, emits the delegation result with `proved`, and exits 4 naming the receiver; the next run hands off afresh in a new worktree. Regression test: `TestDelegateLocalNoChange`
