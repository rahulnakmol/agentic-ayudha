# D-7.1h

## Plan assumption

D-7.1g: a product's default `verify-sweep` has no `setup`, so a web product's behaviour checks have no dependencies or browser in Actions

## Finding

D-7.1g left `setup` and `setup_run` out of the defaults because they install this repository's own example tooling; a product then had to write its own

## Implemented instead

Founder-approved follow-up (2026-10-17). `loops.Defaults(assets, root)` replaces a default loop's `setup` and `setup_run` with the product's, from its lockfiles (`loops.ProductSetup`): `pnpm-lock.yaml` gives node and pnpm, `pnpm install --frozen-lockfile`, `pnpm exec playwright install --with-deps chromium`; `bun.lock` or `bun.lockb` gives bun, `bun install --frozen-lockfile`, `bunx playwright install --with-deps chromium`; both give node, pnpm, and bun, installing with pnpm; `package-lock.json` gives node, `npm ci`, `npx playwright install --with-deps chromium`; no lockfile, no setup. A comment names the lockfile and says to edit it. New pinned tool setup `bun`: `oven-sh/setup-bun@0c5077e51419868618aeaa5fe8019c62421857d6 # v2.2.0` (the v2.2.0 tag commit). Tests: `TestDefaultsSetup`, one row per case, including the pinned `uses:` lines in the rendered workflow; regression `TestInstallLoopsAddsDefaults`, whose codex run now has a `pnpm-lock.yaml` and fails without the change (no `pnpm exec playwright install` in the workflow). **Proven (2026-10-17, plan mode, `install --loops --host claude`, local scratch repositories deleted afterwards):** a pnpm scratch (`pnpm-lock.yaml` from pnpm 12) got `setup = ["node", "pnpm"]` and the two pnpm commands, with `actions/setup-node` and `pnpm/action-setup` in the workflow; a Bun scratch (`bun.lock` from `bun add -d @playwright/test`) got `setup = ["bun"]` and the two Bun commands, with `oven-sh/setup-bun@0c5077e… # v2.2.0`. In each, the install command passed locally (`pnpm install --frozen-lockfile`; `bun install --frozen-lockfile`, then `bunx playwright --version` 1.64.1); the browser install with `--with-deps` needs root and was left to the runner
