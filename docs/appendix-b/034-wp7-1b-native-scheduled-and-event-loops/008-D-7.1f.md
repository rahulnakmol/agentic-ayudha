# D-7.1f

## Plan assumption

S-7.1e: "Amp: fully automatic (`set_schedule`)"; "offer a Run now test"; this repository's daily triage schedule

## Finding

Amp has no CLI command for schedules, `set_schedule` is an agent tool, and one thread holds one schedule (the building-schedules skill), so no single call can set every loop. `amp -x` archives its thread when it finishes unless `--no-archive-after-execute`, and only an orb thread in a project can host a fresh-run schedule. This thread may not start Amp agents through the CLI, so the `--apply` path could not be run live here. The Cursor docs name no "Run now" for an automation; Codex's advise testing the prompt in a chat first; Claude Code has **Run now** and `/schedule run`. The weekly `triage` schedule already lives on this thread
