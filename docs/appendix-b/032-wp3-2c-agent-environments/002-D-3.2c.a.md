# D-3.2c.a

## Plan assumption

S-3.2c: "one shared setup script that every host calls is the likely shape; prove or disprove that"

## Finding

Sources: Cursor [cloud agent setup](https://cursor.com/docs/cloud-agent/setup) and the [environment.json schema](https://www.cursor.com/schemas/environment.schema.json) (`install`, `start`, `terminals`, `build.dockerfile`, snapshots; read from the default branch; a build keeps the disk only); Codex [cloud environments](https://developers.openai.com/codex/environments/cloud-environments) (UI only: Install script, Start skill, the Package managers domain preset, network secrets) and [Legacy environments](https://developers.openai.com/codex/cloud/environments) (setup and maintenance scripts, a 12 h cache, secrets only during setup); Claude Code [cloud environments](https://code.claude.com/docs/en/cloud-environments) (setup script as root on Ubuntu 24.04, Trusted network allowlist, environment variables) and [on the web](https://code.claude.com/docs/en/claude-code-on-the-web) (`claude --cloud`, `SessionStart` hooks with `CLAUDE_CODE_REMOTE`); Amp [orb customizing](https://ampcode.com/docs/orbs/customizing) (`.agents/setup`, `.agents/resume`, the project pre-setup script, 72 h snapshots, Debian 12) and [spawning orbs](https://ampcode.com/docs/cli/spawning-orbs). Every host either runs a repository file (Amp, Cursor, the Claude Code hook) or accepts one command in its UI (Codex), and every base has bash, apt, and root or sudo

## Implemented instead

Proven: one generated `.agents/setup` (pinned versions with SHA-256 for every download; Go by `GOTOOLCHAIN` when a Go exists, else the tarball; Node by the nodejs.org index and `SHASUMS256.txt`; pnpm and yarn through a pinned corepack; uv from its GitHub release; rustup from static.rust-lang.org; system packages through `need_apt`, which makes no apt call on a warm run; root or a sudo user), `.agents/check` (asserts each toolchain version on a login shell's `PATH`, starts the services, runs the build and tests, prints `aayu-env ok <fingerprint>`), and, with services, `.agents/start` and `.agents/resume`. Each host's native file calls them: Amp natively, Cursor `.cursor/environment.json` (`install`, `start`; aayu owns `name`, `install`, `start` and keeps the owner's keys), Claude Code a `SessionStart` hook in `.claude/settings.json` that runs setup only when `CLAUDE_CODE_REMOTE` is `true`, Codex the Install script `bash .agents/setup` printed with the Start skill. A Cursor `build.dockerfile` is not generated: one script serves every host, and Cursor snapshots its result
