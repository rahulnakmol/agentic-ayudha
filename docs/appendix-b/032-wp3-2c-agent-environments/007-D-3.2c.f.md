# D-3.2c.f

## Plan assumption

S-3.2c: "know what the user has"; delegation calls detection on every hand-off

## Finding

The delegation thread asked for no model, task, or network call, injectable probes, no secret values, and exact install and sign-in commands. Local signals checked against the CLIs (installed in a scratch HOME on 2026-10-16): `codex login status` exits 1 when signed out and names ChatGPT or an API key; `claude auth status --json` gives `loggedIn` and `authMethod` (`claude.ai`, `oauth_token`, `api_key`, `apiKeyHelper`, `third_party`, `none`); `cursor-agent status` prints `Not logged in` and exits 0; `amp account list` prints `No saved accounts.` or the `AMP_API_KEY` override

## Implemented instead

`agentenv.Detect(ctx, Probe) []Agent`: per agent the CLI path and version, `SignedIn`, `Cloud`, `CloudDetail`, and `Install` and `SignIn` command lines. Cloud: Codex needs a ChatGPT login and `[delegate] codex_env`; Cursor a `cursor-api-key` secret or `CURSOR_API_KEY`; Claude Code `authMethod` `claude.ai`; Amp a sign-in and an Amp project recorded for this repository by a live probe. `agentenv.Ensure(ctx, root, host, EnsureOptions{})` regenerates and verifies a missing or stale environment before a cloud hand-off, and returns an error wrapping `ErrNotLanded`, whose text is the next command, while the files are not on the default branch. `doctor`'s `agents` row reports Detect; its `agent-env` row reports each host
