# D-3.2c.d

## Plan assumption

S-3.2c: "runs the generated setup in a clean container, or the closest equivalent"

## Finding

No host publishes its exact machine image except Codex (`ghcr.io/openai/codex-universal`, about 44 GB unpacked). An Amp orb is Debian 12 but already carries a current git (2.55 in `/opt/git` on the orb that built this); plain `debian:12` has git 2.39, and aayu requires git ≥ 2.40 (`internal/doctor/checks.go`), so three of this repository's tests failed in the first clean container. bookworm-backports has no newer git. With `set -e`, a failure inside an `a && b \|\| c` list does not stop a script, so a step written that way failed silently

## Implemented instead

Profiles (`agentenv.Profiles`): Amp `debian:12` as `user` with sudo, Cursor `ubuntu:24.04` as `ubuntu` with sudo, Codex `codex-universal:latest` as root, Claude Code `ubuntu:24.04` as root, each with only git, CA certificates, and sudo added. codex-universal's entrypoint configures its language runtimes and then runs bash with the container's arguments, so it is kept (`Profile.BashEntrypoint`). The check runs in a fresh login shell with the image's own environment and nothing setup exported: codex-universal puts its own runtimes (uv 0.7.22 in `~/.local/bin`, nvm's Node, mise's Go) ahead of `/usr/local/bin`, so setup now puts `/usr/local/bin` first in later shells when a pinned uv is shadowed, as it already did for Go; and its mise sets `GOROOT` to its Go 1.25.1, which made the pinned Go 1.27.2 compile with the old tools (`compile: version "go1.25.1" does not match go tool version "go1.27.2"`), so setup resets a foreign `GOROOT` for later shells. `Verify` tars the clone as it would be with the generated files committed, runs setup cold, setup warm (idempotence), then the check in `env -i bash -lc` (an agent's fresh login shell), and records per-phase seconds. Its fix loop (three attempts) adds the apt package for a missing command and marks a dubious-ownership checkout safe, recording each fix as an answer so rediscovery keeps it. This repository's spec carries one human step: build git 2.55.0 from kernel.org (SHA-256 pinned, `NO_RUST`) only when git is older than 2.40, written as `if …; then …; fi` so a failure stops setup. Step labels are now single-quoted, so a label never runs the step's `$(…)`
