# D-6.1a

## Plan assumption

WP0.4: npm licence scan (`security` job) with the allow list Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, MIT

## Finding

The design system is a pnpm workspace with one root `pnpm-lock.yaml` (`.agents/setup` installs from it), so the scan's `npm ci` per `package.json` fails for lack of a `package-lock.json`. Radix UI, under the shadcn/ui components, depends on `tslib`, which is 0BSD

## Implemented instead

The npm step installs with `pnpm install --frozen-lockfile --ignore-scripts` and checks `pnpm licenses list --recursive --prod` against the allow list; dev tooling (Storybook, Playwright, axe-core MPL-2.0) is not distributed and not scanned. 0BSD (public-domain equivalent, no conditions) joins the allow list. GSAP stays out of the scan because it is a peer dependency only (J3-19)
