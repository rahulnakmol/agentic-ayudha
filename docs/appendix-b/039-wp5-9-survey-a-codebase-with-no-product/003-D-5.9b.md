# D-5.9b

## Plan assumption

Decision #287: every finding cites file and line (the evidence rule); unknowns are marked, never invented

## Finding

The evidence rule (AGENTS.md, every seat) asks for a citation per claim, but a claim about who uses a product, for what, and why has nothing in the code to cite; a citation check alone would push a model to cite something loosely related

## Implemented instead

`aayu survey --draft` checks the draft's basis model (`internal/survey.Check`): each claim is `observed`, `stated` (a document or comment says it), `inferred` (with its reasoning), `confirmed` (an answered question, the person's words quoted), or `unknown` (a question asks it). Observed, stated, and inferred claims need a citation that resolves in the index (a fact ID, or a `path:line` range inside the file); a product claim may never be `observed`. Questions are `open`, `answered` (with the quote), or `deferred` (with why); the modernisation target must come from the request's words or an answered question, every step names the case sets that prove its parity, and a behaviour a case set deliberately drops names the claim or question that decided it. The JSON is decoded strictly, so a misspelt key fails instead of dropping claims. `SURVEY.md` lists the limits of the index (ambiguous calls, dynamic dispatch, unindexed files, a shallow history) and the coverage: modules, entry points, and known-issue markers cited, with the uncited ones named
