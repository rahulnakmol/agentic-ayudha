# D-5.9f

## Plan assumption

D-5.9e: a tier-2 survey run reaches the skill model

## Finding

The first dispatch (run 39014616715, `survey/tinyjs-rust`) errored on all five runs with HTTP 524 from the gateway on `claude-opus-5-5` and on its fallback `claude-sonnet-5-5`, at no cost: a survey draft takes minutes to generate, and the proxy in front of the gateway closes a connection that sends no bytes for 100 seconds

## Implemented instead

`models.Request.Stream` asks an Anthropic Messages endpoint for `"stream": true`, and `HTTPClient` reads a `text/event-stream` reply (text deltas in order; model and input tokens, cached input included, from `message_start`; stop reason, truncation, output tokens, and any reported cost from `message_delta`; an `error` event is an error). A gateway that ignores the flag and answers JSON still decodes, and other wire formats ignore it. Only the survey skill call streams for now, since the other case types finish well inside the timeout (`TestMessagesStream`, `TestTier2SurveyRevisesOnceThenJudges`)
