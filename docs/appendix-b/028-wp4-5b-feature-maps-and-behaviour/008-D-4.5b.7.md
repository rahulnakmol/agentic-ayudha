## Implemented instead

In CI, `verify --maintain` posts a **record**: no mention, marker `{"digest", "record": true}`, "Recorded by the Actions loop; no agent was woken". Records are de-duplicated against records and hand-offs against hand-offs, so the nightly record of a drift never stops the person's run from handing the same drift off. The person's run (the same loop's prompt, from `loops/amp/<loop>.json` through `amp -x` on the user's scheduler, or the `cursor_platform_workflow` resources in `loops/cursor/aayudha-loops.tf`) posts the brief with the mention, or for `amp` follows it; `loops/README.md` documents both, with a crontab for `amp -x`.
