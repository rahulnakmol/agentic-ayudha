# D-4.5b.9

## Plan assumption

Q2 of the WP4.5b report: should feature-map directories be protected paths

## Finding

Founder decision 4 (2026-10-16): they are not; the gate's weakened-check flag covers them. Checked against the code: `inspect.Weakened` (P6, #228) flagged test files, CI files, and config thresholds only, so a PR could drop a behaviour check or an assertion unflagged

## Implemented instead

The directories stay unprotected, and `inspect.Weakened` gains a feature-map case for `.agents/skills/verify-*/features/*.md`: fewer `check` blocks ("fewer behaviour checks"), fewer assertion keys (`expect`, `expectText`, `absentText`, `count`, `stdout`, `stderr`, `status`, `exit`, `body`, `test`: "fewer behaviour assertions"), or a deleted feature file. A renamed handle on a changed line is not a weakening. The flag reaches the proof comment and inspect as before. Test: `TestWeakenedChecks`
