# D-4.5b.2

## Plan assumption

WP4.5b.2: the `behaviour` floor hands each check to the control tool; cli and lib checks get no network; evidence kinds as in the Completion Goal

## Finding

The evidence kinds are fixed by the work-item schema (`screenshot`, `recording`, `sr-transcript`, `api-trace`, `metric`). A ui or api check needs the app `[verify] seed` starts, which is PR code, exactly as the WP4.5 web floors run it. Whether a precondition (`requires`) holds is known to the control tool, not to aayu. A PR that serves no story has no pack. The examples in this repository reach Playwright through the base branch's `packages/floors` (D-8.1b)

## Implemented instead

The contract is `<control...> check`, stdin `{product, feature, check, out, base_url, root}`, stdout `{status passed\|failed\|unreachable, reason, artifacts[{path, kind}]}`; malformed output or an artifact path outside `out` blocks the floor, a `failed` check fails it. A CLI or library check's transcript uses the existing `api-trace` kind; no evidence kind is added. ui and api checks run with network allowed (`CheckResult.network`), cli and lib checks isolated. `requires` is interpreted by the control tool, which answers `unreachable` (proving nothing). The merge gate on a PR with no story runs the two map floors only (`verify.MapFloors`). A preview with no pack keeps the floors' artifacts in `.aayudha/state/verify/` (`artifacts_dir`). The Node control tool resolves Playwright from the product's root `package.json`, then `NODE_PATH`. First live gate run: PR #223, 15 of 16 checks passed and one unreachable (`product-events.visit-and-ask`: serve.sh starts no events sink). Live block: PR #234 (a demo, closed unmerged) renamed the benefits-qa "Ask" button and the notes `done` command; the gate (run 38839008282) selected the 11 checks of the touched features and failed 5 (`ask-answer.typed`, `refer-to-hr.typed`, `refusals.personal`, `mark-done.done`, `mark-done.missing`), and the `feature-map` floor reported 5 advisory drift items (the `Ask` handle of three features, the unmapped `finish` and the gone `done` command)
