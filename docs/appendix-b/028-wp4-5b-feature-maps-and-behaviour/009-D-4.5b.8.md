# D-4.5b.8

## Plan assumption

D-4.5b.4: `[verify] maintainer` has no default and is set by hand

## Finding

Founder decision 3 (2026-10-16): this repository uses headless Amp; in a product repository the maintainer is the user's choice, among the agents installed

## Implemented instead

This repository's `.aayudha/config.toml` sets `[verify] maintainer = "amp"`. `aayu init --verify-skill` asks "Which agent maintains the feature maps?" and offers only the agents detected for the repository: amp, codex, cursor, or claude whose CLI is installed and signed in on this machine (`agentenv.Detect`, WP3.2c), or whose GitHub app answered on the repository (`inspect.DetectApps`). The answer is written as `[verify] maintainer` (a value already set is kept); with none detected, no terminal, or an answer it did not offer, nothing is written and init says how to set it. Test: `TestInitVerifySkillMaintainer` (only amp offered; `amp` written; `codex`, not offered, not written)
