# D-6.5a

## Plan assumption

WP6.5: `research`, `wireframe`, `mockup`, `prototype` "as settled", artifacts under `ledger/design/<feature>/`; prototype behind an OpenFeature flag with Code Connect mapping; screenshot diff vs Figma within `[review] figma_diff_max` (2 % of pixels after an anti-aliasing mask) with colour and typography token mismatches counted apart and zero; accept: the eval chain on a fixture feature produces all four with pinned references, a 1.5 % prototype passes and a 2.5 % one fails, a non-token colour fails regardless of pixel diff

## Finding

Built ahead of M4.5 and M6 (founder scheduling, 2026-10-12) with no Figma or Mobbin account. The four verbs run in the host (mode `host`), so the plan leaves open what the binary checks, what "pinned" means, what a token mismatch is, how a flag counts as "behind", and where states come from (a Feature has no criteria). The WP3.4 harness replays calls against a file-serving fake GitHub with no ledger remote, Figma, or Mobbin. Figma's local-variables endpoint is Enterprise-only. Design media on a public ledger meet V3

## Implemented instead

`internal/design` plus one handler per verb (`internal/cli/design.go`). The host writes each stage into a `--from` directory with a `stage.json` (new registry inputs: `research --from --query --platform`, `wireframe\|mockup\|prototype --from`, `prototype --captures`); the binary checks it, refuses Mobbin-origin images in it (the WP6.4 rule), and lands `design/<feature>/<stage>/manifest.json` plus its files on the ledger under the bot, or the founder tagged `identity:human-fallback` (D1). Research: references are https page URLs with an ID (never an image; Mobbin ones must be Mobbin page URLs), from the host and, with `--query`, Mobbin screens through the WP6.4 adapter; notes are Markdown. Wireframes: one file per state (SVG, HTML, Markdown, or an image). Mockups: SVG or HTML per wireframe state; any colour literal that is not a token value fails (exit 3). Prototype: the flag must be a boolean flag in `[design] flags` (flagd JSON, new key, default `flags.flagd.json`) whose default variant is false; every Figma component in `components` needs a Code Connect mapping (figma.com URLs with a node-id in the listed sources); each state (URL path on the `[verify.environments]` target, never production; Figma frame ID) is rendered by the embedded Playwright script at the frame's size and compared with Figma's PNG render (REST `images`, downloaded without the Figma token): a pixel differs above a YIQ distance of 0.1, and pixels that look like anti-aliasing in either image are masked (an independent implementation of the Vysniauskas 2009 detector pixelmatch uses). The gate passes when the percentage is at most `[review] figma_diff_max` (new, 2.0, rendered in CONSTRAINTS.md) and there are zero colour mismatches (computed text, background, visible border, outline, SVG fill and stroke colours that are not token values) and zero typography mismatches (font sizes, weights, and families outside the token scale), plus zero drift between Figma variables and tokens of the same name when the variables endpoint answers. A miss exits 3 and writes nothing. "Pinned": each manifest records the previous stage's manifest by SHA-256, carries research's references forward, and pins Figma frames by the SHA-256 of their render. Media follow the proof rules: text on the ledger; images to the `[proof] media` bucket, else Git LFS on a private repository, else only their hashes (this repository, public, without a bucket). `[design] tokens` (new, default the design system's `tokens.json`). The eval chain is `TestDesignChain` (CI `build`): the host's recorded outputs for a fixture Feature (`internal/cli/testdata/design/orders`) through all four verbs against the fake GitHub, a local ledger remote, the recorded Mobbin MCP surface, and a recorded Figma REST session with generated renders; each stage pins the one before. `TestFigmaDiffTolerance` (generated images: 1.5 % passes, 2.0 % passes, 2.5 % fails), `TestNonTokenColourFailsRegardlessOfPixels`, and `TestPrototypeCaptureWithBrowser` (CI `floors-web`: the fixture prototype in Chromium renders only with its flag on; 1.50 % passes, 2.50 % fails, a non-token colour fails at 0.03 %)
