# D-4.8d.4

## Plan assumption

Twelve review cases, three clean controls (D-4.8b.5)

## Finding

One clean control that every reviewer failed hid behind a group mean of 4.19

## Implemented instead

New `inspect/clean-snapshot-locked`: `race-snapshot`'s story, criteria, and base, with the snapshot copied under the lock, a handler test for criterion 1 and a 100-goroutine test for criterion 2 (passes `go test -race`). It is the clean twin of a defect case, so a reviewer that flags correct locking, or treats the plan's concurrency risk as a finding, fails it. Thirteen cases, four clean controls
