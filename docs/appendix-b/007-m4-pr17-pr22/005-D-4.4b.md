# D-4.4b

## Plan assumption

WP4.4 `deps` floor, found while running M4.5

## Finding

`osv-scanner scan source -r` follows `.gitignore`, so a `build` worktree under the ignored `.aayudha/worktrees/` scanned as empty and the floor passed on nothing (a silent pass, against rule 7). The floor also counted Go advisories that osv-scanner's call analysis reports as not called, which osv-scanner itself, and so the CI `security` job, does not fail on

## Implemented instead

The floor names every lockfile git tracks (`--lockfile`; `go.mod`, npm/pnpm/yarn, Python, Cargo, Ruby, PHP, JVM, .NET, Dart, Elixir, R, and Swift lockfiles, outside `testdata/`, `vendor/`, and `node_modules/`) and passes without scanning only when git tracks none. A group whose every advisory the call analysis marks not called, or unimportant, is reported ("N more not called") but not counted. `TestTrackedLockfiles` covers a worktree inside an ignored directory; `TestParseOSVCallAnalysis` both sides of the call analysis; the real-tools planted fixture still fails (`golang.org/x/text v0.3.0`)
