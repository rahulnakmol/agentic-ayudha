# D-3.4b

## Plan assumption

WP3.4 tier 2 scores every run

## Finding

The live run on 35aea36 (38183844440) scored four runs 5 and recorded the fifth as a floor miss: the model's reply was not JSON on two attempts, a harness and transport defect rather than a skill result, and pass^5 fell to 0

## Implemented instead

Founder decision, 2026-10-12. The judge call asks for structured output (`models.Format`: Responses `text.format` / Chat `response_format`, `json_schema`, strict; a 400 from an endpoint that does not support it is retried once without it, with the schema still in the prompt). `models.Structured` validates every structured reply, retries once, extracts JSON from fences or prose, and returns a `*ReplyError` with the last reply. A run whose judge reply fails to parse or validate twice, or whose skill reply is not JSON twice, or whose call fails, has status `error`: score 0, excluded from pass^k and the mean, with a 240-character excerpt of the reply after credential redaction (`actions.RedactString`). Skill output that is JSON but fails the schema or Ready stays a `fail` scoring 1 (rule 7). pass^k and the mean are over completed runs; `Compare` fails a case with more than one errored run (`MaxErrors = 1`)
