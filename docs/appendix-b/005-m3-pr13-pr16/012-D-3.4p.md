# D-3.4p

## Plan assumption

D-1.6a and WP3.4: cost is the endpoint's `usage.cost`, else `[[models.prices]]`, else a fallback of 15/75 USD per million tokens; each group's `max_usd` caps that cost

## Finding

The AI gateway returns no cost, and no repository or default config sets `[[models.prices]]`, so every eval call was charged at the fallback rate: in run 38980397572 (7542b85) each group's recorded `cost_usd` equals its calls' tokens at 15/75 exactly (109.07 USD over six groups). At the providers' list prices the same tokens cost 25.16 USD with all input at the base rate, or 28.35 USD with all input billed as cache writes, about 4x less (review 18.89 → 1.98, conversations 60.08 → 15.60, personas 13.35 → 3.44, skills 7.09 → 1.76, brief 3.69 → 0.89, brief-plain 5.96 → 1.50). The gateway's own billing is not visible from the repository or CI: whether it bills the list price is unverified

## Implemented instead

`models.ListPrices` holds each registry model's published rates (input, cached input, cache write, output, and long-context rates with their threshold), each with its official pricing page and the date read (2026-10-17): Anthropic (platform.claude.com pricing: Opus 5.5 4/0.20/5/20, Sonnet 5.5 2/0.10/2.50/10, Haiku 5.5 0.10/0.01/0.125/0.50 up to 100k prompt tokens, Fable 5.1 10/0.25/12.50/50), OpenAI (developers.openai.com pricing: gpt-6.1-sol 2/0.10/2.50/10, gpt-6-astra 10/1/12.50/50, long context past 272k), xAI (docs.x.ai pricing: grok-4.7 2/0.50/6, long from 200k), Google (ai.google.dev pricing: Gemini 3.1 Pro, which the gateway serves as gemini-3.1-pro-low, 2/0.20/12, long past 200k). `models.Cost`: the endpoint's cost, else a `[[models.prices]]` entry (which gains `cached_input_usd_per_mtok` and `cache_write_usd_per_mtok`, for a gateway that bills otherwise), else the list price, else the fallback. The clients now read cache reads and writes (Anthropic `cache_read_input_tokens` and `cache_creation_input_tokens`; OpenAI `input_tokens_details.cached_tokens` and `cache_write_tokens`, since GPT-5.6 and later write prompts to the cache implicitly at 1.25x input; chat `prompt_tokens_details.cached_tokens`) and count reasoning tokens a chat endpoint reports only in `total_tokens` as output. The [budget] breaker and `inspect` use the same prices. A call charged at the fallback rate is counted by model and listed in the results' `warnings` (and as a `::warning::` in the job log). `TestEvalModelsArePriced` fails when the judge, a lane's direct-host default, alternative, or escalation, or a peer-review candidate has no list price with a source and date. The groups' `max_usd` values are unchanged, so each now buys about 4x the runs it did
