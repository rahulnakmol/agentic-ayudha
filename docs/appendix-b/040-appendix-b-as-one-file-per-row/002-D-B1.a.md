# D-B1.a

## Plan assumption

Story 397: the table is rendered by `go generate` and committed.

## Finding

A committed rendering changes the same lines whenever two branches add a row to one section, or each add a section at the end: the conflict this story removes, moved into a generated file.

## Implemented instead

The rendering is printed on demand (`go run ./internal/appendixb/gen -print`) and not committed. `docs/BUILD-PLAN.md` ends in a generated pointer that names no row, and the Appendix B heading says where the rows live and which command prints them. No link pointed at an Appendix B section anchor, so none broke. A two-way door, decided for the founder on 2026-10-17; the founder can reverse it.
