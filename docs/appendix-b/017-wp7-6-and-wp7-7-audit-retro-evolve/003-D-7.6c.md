# D-7.6c

## Plan assumption

WP7.6 follow-up (founder decisions, 2026-10-12, on the first live audit): a protected-path merge whose "Solo-mode bypass" record came after the merge (#86, rule suite 4473766681) and stories merged after the merge gate without `ship` (#53–#56, #59, #60, #62, #64–#68)

## Finding

The first live report listed #86 as the only unexplained bypass; the founder verified it (only `.github/workflows/inspect-live.yml` was protected; every other required check was green at the merged head), posted a late "Solo-mode bypass (recorded late …)" comment, and wrote `audit/2026-10-12/incident-pr86-missing-bypass-comment.md` on the ledger. Stories merged after the gate without `ship` have no authoritative pack and stayed `status:ready`; the founder decided they are done but unproven, with no retroactive ship records

## Implemented instead

A bypass that would be an ordinary solo-mode bypass but has no prior comment is classified "solo-mode bypass, recorded late" (its own class and section, counted apart in the summary, listed only when present so earlier reports replay unchanged) when a later PR comment starting "Solo-mode bypass" or a ledger note `audit/<date>/incident-*.md` names its rule-suite ID; the rule-suite IDs a comment names are read before the comment is cut for the snapshot (`Event.Suites`). Anything else without a prior comment stays unexplained. Stories merged without proof after the gate are "merged without proof (post-gate)" in the report (pre-gate ones keep their label), both uncovered. `audit --mark-merged` now also takes post-gate stories: same status move through `internal/actions`, a distinct replace-in-place comment (`<!-- aayudha:audit-post-gate -->`, "merged after the merge gate existed, but without `aayu ship` … no ship record is made after the fact"), and it refuses covered stories, stories with no merged PR, and stories already released, measured, or done. A report written before this change replays with the binary that wrote it (the post-gate label is new). Tests: `TestAuditBypassRecordedLate` (a late comment naming another suite stays unexplained; one naming the suite, or an incident note, makes it recorded late), `TestClassifyBypasses`, `TestAuditMarkMerged` (post-gate story #60 in the fixture)
