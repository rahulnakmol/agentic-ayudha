# D-8.1f

## Plan assumption

WP4.5: the web floor runs axe on every Completion Goal state; WP8.1: the example sends `Content-Security-Policy: default-src 'self'`

## Finding

axe-core is injected with `page.addScriptTag`, which a page's own CSP blocks, so the `a11y` floor could only be `blocked` on a page with a strict CSP

## Implemented instead

Fixed through #124 before the UI story: the web floor and review lane B set Playwright's `bypassCSP: true`; `TestWebFloorsWithBrowser` gained a strict-CSP fixture page (fails without the fix). A stale local `aayu` binary built before #124 later blocked #134's per-checkpoint verify twice on L09 (a never layer), which set `status:blocked`; the merge gate (authoritative) had passed every web floor. After rebuilding the binary, `aayu ready 134` (agent lane) restarted the budget, as `build` prescribes
