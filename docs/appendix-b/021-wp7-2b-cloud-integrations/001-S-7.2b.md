# S-7.2b

## Plan assumption

WP5.2, WP7.2, and WP4.2 read Azure, AWS, and GCP only as export files, and the media bucket speaks only S3/R2 (D-4.2a, D-5.2a, D-7.2a)

## Finding

Founder request (2026-10-12, relayed by the orchestrating thread): first-class Azure, AWS, and GCP integrations, so a product on any of the three clouds measures live, satisfies V3 with its own storage, and is set up with least privilege. This extends the plan; it replaces nothing

## Implemented instead

WP7.2b (WP7.2b.1 read adapters, WP7.2b.2 media buckets, WP7.2b.3 setup and docs) added after WP7.2, built as three PRs to `dev`. No cloud SDK: each API is called with `net/http`, the AWS signer is WP4.2's `internal/proof/sigv4`, and the Google service-account JWT is signed with `crypto/rsa`, so CGO stays off and no dependency is added (THIRD_PARTY_NOTICES.md is unchanged). No Azure, AWS, or GCP account exists yet, so every fixture is synthetic and labelled so; the founder actions are listed in WP7.2b.3's getting-started pages
