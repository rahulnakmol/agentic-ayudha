## Finding

Founder decision, 2026-10-12: the extra screen-reader criterion is the stub's defect class (D-3.4c), so it gets the same treatment, not another dispatch

## Implemented instead

The grill skill and `references/story.md` say a Completion Goal states only what the request or its parent asks for: accessibility, performance, and security are floors `verify` enforces on every story and are not criteria unless requested, nor are checks for users the request does not mention. `grill/story-empty-claims` gains five `scope` rules (screen reader, keyboard or focus, other accessibility, performance budgets, claimants who already have claims), checked in tier 1 and before the judge in tier 2; `TestGrillStoryScope` keeps both sides (the recorded criteria and a reworded requested one pass, each unrequested kind fails)
