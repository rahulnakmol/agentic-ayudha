# D-5.5a

## Plan assumption

WP5.5: `build` refuses unless Ready and the body hash equals the snapshot; per-story lease (assignee + lock comment with TTL); worktree `.aayudha/worktrees/<id>` from `origin/dev`; `Aayudha-Checkpoint: n/N` commits; replace-in-place progress comment and checkpoint record on `ledger`; `verify` per checkpoint; `[autonomy] budget {wall, cost, attempts}` → `status:blocked` + page on breach or a second failure on a never layer; `--resume` from the last trailer; retries 429/5xx with jitter. `ship`: green gate; human pass = approving review from the seat's human (solo → `[autonomy] approver`), `type != Bot`; never layers need CODEOWNER approval regardless of streak; approval ID and streak state written to the pack; squash-merge; Complete section; `merged`; cleanup. `gc` prunes stale worktrees and leases. Accept: dogfood story Ready → merged; a bot review is rejected as a pass; a stale lease is reclaimed by `gc`

## Finding

The plan names no TTL, no way to find leased stories, and no home for the checkpoint record. The binary never sees the host model's spend. Floors whose tools are absent fail by rule 7, and most laptops lack the pinned scanners. A POST or PATCH that answered 5xx may have landed. The pack is the merge gate's verified artifact, written before `ship` runs. aayudha has no `[autonomy] approver` and one human, so GitHub refuses the only possible approval (D2)

## Implemented instead

Lease: the lock comment `<!-- aayudha:lease holder=<login>@<host> expires=<UTC> -->`, the holder's login as assignee (an App's `[bot]` login cannot be assigned), and the new label `aayudha:leased` so `gc` and `doctor` find leases; `LeaseTTL` is 4 h, renewed by every build run; a live lease of another holder refuses the build (exit 4); an expired one is taken over. A story branch already on origin without a local worktree needs `--resume`, which cuts the worktree from that branch and reports its last `Aayudha-Checkpoint` trailer. N is the plan's checkpoint count when `specs/<n>/plan.json` is on the ledger (WP5.4), else the larger of k and the change's layer count; a retry of a checkpoint that missed keeps its k and adds `Aayudha-Attempt: <a>`. Each checkpoint runs `aayu verify` in the worktree; a floor that fails only because its tool is not installed there is reported but does not count (the merge gate runs the pinned tools and stays authoritative). `build/<n>/state.json` on the ledger holds the start time, checkpoints with their verify result, failed attempts, failures per layer, and any block; the `<!-- aayudha:progress -->` comment shows the same with the budget. Budget: wall time since the first run, spend from the story's actions-log costs plus the host's `AAYU_COST_USD`, and failed checkpoint attempts; a breach, or a second miss on an `[autonomy] never` layer, sets `status:blocked`, pages through `[notify]`, and exits 4; a human's `aayu ready` restarts the budget. The GitHub transport retries a 5xx with exponential backoff from 1 s only where repeating cannot write twice (GET, HEAD, PUT, DELETE, GraphQL queries), and adds up to 25 % random jitter to every wait, the rate-limit waits included. `ship`: the human pass must come from the Engineering Manager seat's paired human, else the `[autonomy] approver`, else any human who is not the author (bots and `[identity] bot_logins` never count); when the pack's footprint meets `[autonomy] never`, the approver must also be a CODEOWNER (base-branch CODEOWNERS) of every changed path in those layers, whatever the streak, and the EM's plan-time review must be approved on the ledger. The streak is computed at ship time from merged-PR history (WP5.7); a footprint the streak makes autonomous with no never layer ships without a review (`human_pass.kind = autonomous`). The approval ID, the pass rule, the never layers, the plan review, and the streak state go into `ship.json` beside the authoritative pack, not into `pack.json`, which stays as the gate wrote and verified it. `ship` releases the lease. `--solo-bypass` stays the human-only path (D-M4.5a). `gc` (human identity) reclaims expired leases, leases of closed stories, and stray labels, and removes the worktree and local branch of a closed story when nothing in it is uncommitted or unpushed (else keeps it, saying why); `doctor`'s `leases` check lists stale leases
