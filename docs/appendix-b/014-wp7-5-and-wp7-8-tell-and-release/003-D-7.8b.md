# D-7.8b

## Plan assumption

WP7.8: `release` stamps the stories it ships `released`

## Finding

Found running the first `aayu release` on aayudha (Release #147). `release` read only the first `Refs #n` of a merged PR, so #97 (`Refs #64`, `Refs #65`) shipped #64 but not #65; and it stamped any story a PR in the range referenced, including stories that never merged (the WP8.1 umbrella #70, referenced by PR #142 alongside story #130), which would claim undone work

## Implemented instead

`release` reads every `Refs`/`closes` line of a merged PR (#146). A referenced story that is not `status:merged` and not listed by the Release is reported as "referenced but not merged" and not stamped; it adds no measure obligation. Listed stories still must be in the range or already released
