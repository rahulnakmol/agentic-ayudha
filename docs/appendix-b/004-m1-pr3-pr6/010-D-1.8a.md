# D-1.8a

## Plan assumption

WP1.8: OTel traces to a file, OTLP opt-in

## Finding

`go.opentelemetry.io/otel` v1.47 requires Go 1.26 (D5 keeps the 1.25 floor), and the upstream OTLP exporters pull in gRPC and protobuf

## Implemented instead

`go.opentelemetry.io/otel` and `otel/sdk` v1.46.0. Both exporters are in `internal/telemetry` and write OTLP JSON: one request per line in `.aayudha/telemetry/traces.jsonl`, and, only when `[telemetry] otlp_endpoint` is set, a POST to `<endpoint>/v1/traces`. The `OTEL_*` variables are ignored so nothing is sent by accident; `[telemetry] disabled = true` writes nothing. Each command run is one span with its exit code
