## Implemented instead

The test drives `init`'s action plan (labels, issue type, form, `ledger` ref) through `actions.Do` with `--dry-run` against a fake GitHub: every record is `planned`, the server sees zero requests, and the chain verifies; WP2.5 reuses the same path. The log is `.aayudha/telemetry/actions.jsonl` in a checkout (XDG state dir elsewhere), git-ignored; segments go to `.aayudha/ledger-outbox/actions/<date>/<host>-<run>.jsonl` until the ledger writer exists (WP2.4). A capability is enforced twice: `Do` checks the action's declared request before calling anything, and `actions.Guard` wraps the HTTP transport so a perform function cannot exceed it. `aayu actions verify-chain` exits 4 on a broken chain
