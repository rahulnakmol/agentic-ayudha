# D-1.6a

## Plan assumption

WP1.6: one client per provider (Anthropic, OpenAI, Google, xAI)

## Finding

Founder, 2026-10-11: models are reached through one AI gateway (repo environment `ai-gateway`: secret `AAYU_SECRET_AI_GATEWAY`, variable `AAYU_AI_GATEWAY_URL`) that speaks Anthropic Messages, OpenAI Responses, and OpenAI Chat Completions on one base URL with a Bearer key. Model IDs verified there: `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`, `claude-fable-5-1` (Anthropic, not Google), `gpt-6.1-sol`, `gpt-6-astra`, `grok-4.7`, and only `gemini-3.1-pro-low`. No JSON Schema validator is on the §2 list

## Implemented instead

`[models.gateway] base_url secret api_style styles` routes every lane through the gateway; without it each family uses its direct provider (Anthropic Messages, OpenAI Responses, Google and xAI Chat Completions; key secret named after the family). Wire format per model: a `styles` entry for the model ID (`"grok-4.7=chat"`; a list because IDs contain dots), then for its family, then `api_style`, then the family default (anthropic → messages, openai → responses, others → chat). Family is inferred from the model ID, never the endpoint, so reviewer ≠ builder holds through one gateway. The registry carries the IDs (Gemini note: `gemini-3.1-pro-low` substitutes for Gemini 3.1 Pro; Fable is an anthropic alternative, valid only when the builder is not anthropic); heavy reviews use `gpt-6-astra` at high effort; Cursor excludes the openai family, so a GPT lane on Cursor falls back to Grok and logs it; a direct call where the host default is host-managed (Amp) uses the Claude Code default. Cost: the endpoint's reported `usage.cost`, else `[[models.prices]]`, else a deliberately high fallback rate (15/75 USD per million tokens) so an unpriced model trips the breaker early. The breaker trips when spend reaches the limit (the boundary trips), writes `.aayudha/state/paused` (agents' verbs exit 6 until a human clears it; `aayu resume` is WP5.7), and pages once per scope per day. `[notify]` gains `issue`, `smtp_addr`, `from`, `smtp_secret`. Structured output validates against an in-house JSON Schema subset (`models.Schema`). Live calls: `TestGatewayLive` behind `AAYU_LIVE=1`, run by `models-live.yml` on pushes to `dev`, daily, and on dispatch with `environment: ai-gateway`, never on PRs, green-skipping while the secret is absent
