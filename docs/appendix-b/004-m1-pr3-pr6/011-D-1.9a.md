# D-1.9a

## Plan assumption

WP1.9 accept: v1 → v2 byte-exact diff; v1 pack passes `proof verify` on v2; v3 repo refused by a v2 binary

## Finding

This binary is the first with versioned files: config is v1, and `lock.toml`, `state.json`, and proof packs (WP3.2, WP2.5, WP4.1) do not exist yet

## Implemented instead

`internal/upgrade` migrates `.aayudha/config.toml` and `config.local.toml` (`version`), `lock.toml` (`version`), and `state.json` (`schema_version`) as text, so comments survive; it never touches `ledger`. The byte-exact test runs a simulated v2 binary's migrations over a v1 fixture repo against a hand-written expected diff, then re-plans to zero changes; a v3 fixture is refused by the simulated v2 binary. In the real CLI a write verb (every verb except `doctor`, marked `ReadOnly` in the registry) on a repository newer than the binary exits 2 with the `aayu self-update` hint. `upgrade --apply` is refused for agents. Pack readers per schema version (`proof verify`), the per-story schema column in `status`, and skill-copy migration are n/a until WP4.1, WP2.8, and WP3.2
