# D-1.2b

## Plan assumption

WP1.2 layer list "`AAYU_*` → flags" and section keys

## Finding

The plan names no environment-variable or flag syntax, and gives keys without units

## Implemented instead

Env layer: `AAYU_<SECTION>__<KEY>` (double underscore between levels, e.g. `AAYU_BUDGET__PER_DAY_USD`); other `AAYU_*` variables (`AAYU_AGENT`, `AAYU_LIVE`, `AAYU_SECRET_*`, `AAYU_GITHUB_TOKEN`) are not configuration. Flags layer: a new global `--set key=value` (repeatable). Keys carry units: `[decisions] sla_hours provisional_after_hours` (business hours), `[proof] retention_days`, `[autonomy.budget] wall_hours cost_usd attempts`, `[lfs] quota_warn_percent`. The defaults layer is WP0.5's `internal/config/defaults.toml`, extended with `[lfs]`, `[decisions]`, and `[time]` defaults (Europe/London, Mon–Fri 09:00–18:00), which `CONSTRAINTS.md` does not render. A file without `version` is v0 (plan v0.1); v0→v1 drops `[lfs] server = "github"` and refuses any other server (V6). `[models.gateway]` (founder request) routes model calls through one AI gateway; see WP1.6
