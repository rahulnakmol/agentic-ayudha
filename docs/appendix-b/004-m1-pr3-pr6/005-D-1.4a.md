# D-1.4a

## Plan assumption

WP1.4: token broker "returns [the token] encrypted to the caller's ephemeral age key"

## Finding

A `workflow_dispatch` run has no return channel, and `actions/create-github-app-token` revokes its token when the job ends

## Implemented instead

`aayudha-token.yml` (embedded template, installed by `init --gates`, WP2.6) validates the inputs, mints with `skip-token-revoke: true`, encrypts `{token, expires_at = now + 55 min}` to the caller's one-time age key, and uploads it as a one-day artifact named by the request ID; the client finds the run by `run-name`, downloads and deletes the artifact, and refuses a token that is expired or outlives 1 h. Tested against a fake GitHub; the live round-trip is `TestBrokerLive` behind `AAYU_LIVE=1` and `AAYU_LIVE_BROKER_REPO`, which needs the founder to create the App. CI uses `AAYU_BOT_TOKEN` from `actions/create-github-app-token`; with `--ci`, bot and ledger writes are refused without it or when it equals `GITHUB_TOKEN` (D1)
