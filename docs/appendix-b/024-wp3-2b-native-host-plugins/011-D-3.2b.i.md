# D-3.2b.i

## Plan assumption

WP3.2b: doctor detects a Cursor plugin installed from a marketplace

## Finding

PR #279 open point (1), accepted by the founder as a limitation: `agent plugin marketplace add` needs a sign-in and records the install with the Cursor account, and no local file shows it (cursor.com/docs/plugins)

## Implemented instead

aayu sees only `~/.cursor/plugins/local/*/.cursor-plugin/plugin.json`. The Cursor host guide says so, and doctor's `skills-copies` row adds the line "Cursor: aayu sees an aayudha plugin only in ~/.cursor/plugins/local, not one installed from a marketplace …" whenever Cursor is installed. Test: `TestInstall`
