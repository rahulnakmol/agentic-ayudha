# D-5.3b.a

## Plan assumption

WP5.3b: a deterministic, read-only fact pass the host consumes

## Finding

No convention tells a binary which code an idea touches, and "touched" cannot be decided by rule. GitHub search would be a second network dependency; MCP tools must not write

## Implemented instead

New registry inputs `grill --assess` (bool) and `--idea` (string); `internal/grill.Assess` reads only the checkout (skipping `.git`, `node_modules`, `vendor`, `testdata`, build output; at most 20 000 files, 512 KiB each) and, when a client exists, one page of the repository's `type:story` issues. Relevance is the idea's own words (stop words and the qualifiers removed, stemmed) against route paths, file paths, event names, and story text; when no route matches, every route is listed and the scope line says so. Routes: Next.js `app/**/page.*` and `route.*` (route groups and slots dropped) and `pages/**`, SvelteKit `routes/**/+page.svelte` and `+server.*`. A screen has a state when a convention file (`loading.*`, `error.*`, `empty.*`, `offline.*`) is in or above its directory, or a marker (`isLoading`, `error`, `isEmpty`, `navigator.onLine`, …) is in its own files; a missing state is a `gap:<state>:<flow>` fact listing the screens. Other facts: `flow`, `route`, `component` (used on the matched screens or in a `ui`/design-system directory), `ds` (UI libraries in `package.json`, a local design-system package), `tokens` (CSS custom properties in token files, Tailwind config, `design/brand.yaml`), `test`, `event` (`capture`, `track`, `logEvent`, and `gtag('event', …)` calls), `code`, `story:#N` with its first criteria, `floor` (a11y, Lighthouse, k6, platforms from config), and `layer`. Facts are sorted and carry no timestamps, so the same checkout gives the same report. Every text is one cleaned line; the text report puts all facts in one `<untrusted source="repo">` block and the JSON carries an `untrusted` note. No GitHub client or no answer is a note, not a failure. `grill` is a read verb, so `--assess` is exposed over MCP; the `grill` prompt takes `idea` and, for a story or bug, embeds the same report as untrusted data. These are heuristics: a fact names its evidence (file, marker rule) so the human can correct it in the conversation
