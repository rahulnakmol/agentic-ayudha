# aayudha: your bot App is created

GitHub sent you here after you confirmed the aayudha bot App.

**Copy this page's whole address from your browser's address bar, and paste it into the terminal where
`aayu init --identity` is waiting.** The address carries a one-time code. aayu turns it into the App's key and stores
the key where the App's identity setup says, never on your device.

- Do not share the address with anyone or anything else: whoever turns the code into a key first holds the App.
- Install the App only when `aayu init --identity` gives you the Install link.
- If aayu says the code was not converted, do not install the App. Delete it in your
  [GitHub App settings](https://github.com/settings/apps) and run `aayu init --identity` again.
- If you did not just run `aayu init --identity`, delete the App the same way.
