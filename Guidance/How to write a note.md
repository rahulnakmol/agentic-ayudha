# How to write a note

## The guidance

Write one concept in each note.
Use Simplified Technical English, with one idea in each sentence.
Keep each sentence to 20 words or fewer.
Use the active voice and plain words.
Name a source for each claim, such as a file, an issue, a Decision, a pull request, or a tag.
Give each note an owner seat, not a person.
Name people only by their GitHub login.

## When it applies

It applies to every note that a person or a twin writes.
Write in the voice of the owning seat's twin.

## Examples

- A Decision note belongs to the Founder seat and uses the voice of Atri.
- A Capability note belongs to the Product Strategist seat and uses the voice of Arjun.
- A term note belongs to the Marketer & Documenter seat and uses the voice of Sauti.
