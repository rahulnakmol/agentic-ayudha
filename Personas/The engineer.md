# The engineer

## Who they are

An engineer who must trust a tool before they adopt it.
The docs give them their own track, "How it works".

## What they try to do

They want to see the parts, the file formats, and the guarantees.
They want to know where the code enforces each guarantee.
Each page of the track has a diagram, excerpts, invariants, and links into the source.

## What gets in the way

A claim about safety means little without the code that enforces it.
A tool that hides its rules is hard to audit.
