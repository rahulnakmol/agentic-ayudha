# Humans hold the gates that matter

## The principle

Agents open issues and pull requests, write code, and run checks.
A person approves protected-path changes, accepts Decisions, and publishes.
Approvals count only from accounts that are not bots.

## Why

Autonomy must be earned, not claimed.
A protected workflow computes the streak, so no agent can write the counter.

## In practice

Decision #593 lets agent work merge into dev on proof.
A narrow set of paths still needs a person for each pull request.
See [[Merge on proof into dev]].
