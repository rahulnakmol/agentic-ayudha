# Saving the claims you picked

Now a reviewer can save just the claims they picked into one file, and each one does it about four times a week [R].

## What it does

A claim is a note that asks for money. Reviewers check long lists of them. Before, they copied claims by hand, and it took hours [#7].

Now they pick the claims they want. Then one button saves them to a CSV file. A CSV file is a plain table that most computers can open [#12].

The file has only the claims they picked. It has only the rows and boxes they can see. The list still works while the file is made, even with more than 10,000 claims [P1].

## How we know it works

Robot tests checked each of these things before the change went in [P1]. Each reviewer now saves about four files a week, and the goal was three [R].
