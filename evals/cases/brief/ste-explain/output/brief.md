# Export of filtered claims

Reviewers can export the claims that they filter to a CSV file [#7].

## What the export does

The export writes all claims that match the filters [P1]. The export writes only the columns that you see [P1]. The list continues to work while the export makes the file [P1]. This is correct for lists of more than 10,000 claims [P1].

## Tests and results

The merge gate did a check of the change before the release [P1]. The coverage was 94 percent, and the limit is 90 percent [P1]. The rate is 4.2 exports per reviewer per week [R]. The target is 3 exports per reviewer per week [R].
