# Export of filtered claims

Users can export the claims that they filter to a CSV file [#7].

## What the export does

The export writes all claims that match the filters [P1]. The export writes only the columns that you see [P1]. The list continues to work while the export makes the file [P1]. This is correct for lists of more than 10,000 claims [P1].

## How to export claims

1. Open the claims list.
2. Set the filters.
3. Select the columns that you need.
4. Click Export CSV.

## Tests and results

The merge gate did a check of the change before the release [P1]. The coverage was 94 percent, and the limit is 90 percent [P1]. Users do 4.2 exports each week, and the target is 3 [R].
