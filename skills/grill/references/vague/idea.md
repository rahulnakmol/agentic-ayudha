# Vague: rough idea (`idea`)

Qualifiers: maybe, something like, some kind of, some sort of, sort of, kind of, rough idea, what if, thinking about,
somehow, or something, etc, and so on, revamp, overhaul

A rough idea or a direction ("something like a loyalty thing", "what if customers could reorder") has no user, no
outcome, and no edge yet. The gate also sends any request that names nothing observable here. Work it through like a
product team: who it is for, the job, the outcome and how it is measured (the Goal), the smallest slice that proves
it, what is out, and the checkpoints the human will see while it is built.

## Dimensions

### Who it is for (`idea.who`)

- Ask: Who is this for, and who is it not for? Do they use it today, and how often?
- Default: the one kind of user the request names, because two audiences make two stories.
- Evidence: recording
- Facts: product, route, command, story
- Topics: user, not-for

### The job (`idea.job`)

- Ask: What are they trying to get done, what do they do today instead, and what goes wrong?
- Default: today's way of doing it, from the facts, as the baseline to improve on.
- Evidence: recording
- Facts: flow, route, command, event
- Topics: job, today

### Outcome and goal (`idea.outcome`)

- Ask: What changes when this works, and how would we see it: a number that moves, a task that becomes possible, a
  complaint that stops? Does it serve a Goal you already track?
- Default: one measurable outcome as the story's Measure and Threshold, with the number the human gives; a new Goal
  (`aayu grill goal`) only when they want to track it beyond this story.
- Evidence: metric
- Facts: event, story
- Topics: change, measure, goal

### Smallest provable slice (`idea.slice`)

- Ask: What is the smallest version a user can try that would prove the idea is worth more?
- Default: one task end to end, everything else parked; when it is bigger than an L story, propose `aayu slice`.
- Evidence: recording
- Facts: flow, layer
- Topics: smallest-slice, size

### Out of scope (`idea.out-of-scope`)

- Ask: What is explicitly not in this, even if it sounds related?
- Default: whatever the human has not confirmed is parked, named in Parked ideas.
- Evidence: recording
- Facts: story
- Topics: not-in-scope

### Checkpoints (`idea.checkpoints`)

- Ask: What would you like to see or try at each step while it is built?
- Default: one checkpoint per thing a user can see, in the order it can be built, each naming the criteria it
  reaches.
- Evidence: recording
- Facts: layer
- Topics: checkpoints
