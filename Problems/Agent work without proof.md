# Agent work without proof

## The problem

A coding agent can write a feature in an afternoon.
Whether the feature does what you promised is a different question.
So is whether it is safe to merge, and whether it helps anyone.
An agent saying "done" answers none of these.

## Who has it

Anyone who merges work that a coding agent wrote.

## Evidence

The README states the problem in its first lines.
ETHOS.md rejects "the model says it is fine" as evidence.
See [[Proof, not claims]].
