## Planned, not built

1. **Form field (P1).** Add "Where it happens" to the Bug type in `internal/workitems/schema.go`; `go generate` writes
   both form copies.
2. **Triage decision (P2).** A human-only `--decide` input (and `--reason`) on `triage`. It runs the presence check,
   hashes the repro report, and writes `specs/<bug>/triage.json` with the decision and the hotfix path (ordinary or
   emergency) through the ledger writer. Update the registry entry, the skill, and `GLOSSARY.md`.
3. **Ready rule (P3).** In `r.Covered`, a `bug` case reads `specs/<bug>/triage.json` and refuses Ready unless the
   decision is `hotfix` (#879 Summary). The guard does not run it (#861, F4).
4. **TRIAGE card (P4).** A TRIAGE Need kind (#873) or an `InboxItem` kind that runs P2's command. #879 also lists
   `internal/cli/respond.go`; the reason is not stated (an Incident's linked Bug, inferred).
