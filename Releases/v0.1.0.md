# v0.1.0

## Intent

v0.1.0 is the first stable release of the pod.
It brings milestones M0 to M7 of the build plan, plus docs and installers.
Release issues #145 and #147 carried the rolling snapshots that led to it.

## Objectives served

- [[Ship aayudha 0.1]]: Goal #29 targets the 0.1 release on main.
- [[Prove every Story of aayu itself]]: Initiative #30 tracks proof coverage.

## Out of scope

The build plan limits 0.1 to GitHub LFS for proof media.
The custom transfer agent for other stores comes in 0.2.
Stories merged before the merge gate carry no authoritative pack.
They stay uncovered in proof coverage.

## Outcome

The tag v0.1.0 was published on 2026-10-15.
