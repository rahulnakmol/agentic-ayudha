# Verb

## Meaning

A verb is one of the user-facing commands, such as grill, build, or ship.
The verb registry declares each verb once.
Each verb runs as a CLI command, and most also run as a host skill and an MCP tool.

## Not to be confused with

A plumbing command, such as config or auth, supports the verbs but is not a verb.
