# Layer

## Meaning

A layer is one of nine application layers, from L01 Experience to L09 Platform and operations.
A path belongs to the layer whose glob in LAYERS.md matches it.
Each layer has one owner seat.

## Not to be confused with

A layer is not a seat.
The set of layers a change touches is its footprint.
See [[Footprint (term)]].
