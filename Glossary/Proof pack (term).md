# Proof pack

## Meaning

A proof pack is a pack.json file plus artifacts for one pull request head commit.
It maps every Completion Goal criterion to evidence.
It records the result of each floor.

## Not to be confused with

An authoritative pack is the one the merge gate built in CI.
A pack that an agent pushes is only advisory.
See [[Floor (term)]].
