# Completion Goal

## Meaning

A Completion Goal is the set of numbered, observable criteria a Story or Bug must meet.
Each criterion names the kind of evidence that proves it.

## Not to be confused with

A Completion Goal is not a task list.
It says what done looks like, not how to build it.
The issue holds it, and a note never copies it.
See [[Link issues, do not copy them]].
