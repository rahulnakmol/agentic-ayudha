# Ledger

## Meaning

The ledger is an orphan branch that holds records.
It holds Ready snapshots, proof packs, action segments, and audit reports.
It never holds code.

## Not to be confused with

The ledger is not dev, rolling, or main.
Those branches hold code, and the ledger is never merged into them.
See [[The ledger]].
